## 这门生意的本质 (设计的出发点)

定制印刷买家付款时产品不存在, 他买的是「一个看不见的结果的确定性」。
所以页面的唯一任务 = 把不确定变成确定。买家按固定顺序问 4 个问题:

- Q1 你做不做得出我要的效果? (品质证明)
- Q2 多少钱? (价格透明)
- Q3 什么时候能拿到? (交期)
- Q4 出问题怎么办? (信任与风险逆转)

你的页面结构必须按这个顺序解答, 先答最急的 Q2+Q3。

## 美术指导: 「印刷标本 / Print Specimen」(本次设计的灵魂)

**把每个产品当作一件印刷标本、一份博物馆藏品档案来呈现。**
用印刷行业自己的视觉语言, 让访客潜意识感到「这家公司懂印刷」。

### 视觉母题 (纯 CSS/SVG 实现, 克制使用)

- **裁切标记 (crop marks)**: 卡片/图片容器四角的 1px 墨色 L 形裁切线, 长 12px
- **套准十字 (registration cross)**: section 之间的分隔元素, 1px 细线十字 + 圆, 直径 18px, 居中
- **标尺刻度**: 价格阶梯图的坐标轴用细标尺刻度样式
- 这些元素是「印刷感」的来源, 但每屏最多出现 1-2 处, 多了就是噪音

### 色彩 (严格执行)

```css
:root {
  --paper:#FAFAF8;    /* 纸白, 微暖, 页面主底 */
  --ink:#1E1E1C;      /* 墨色, 正文 */
  --gray:#6B7280;     /* 次要文字 */
  --line:#E5E7EB;     /* 分隔线 */
  --blue:#2873F5;     /* 功能蓝: 链接/选中态/图标容器 */
  --blue-deep:#0f1f3d; /* 藏青: 仅数据带/权威区 */
  --orange:#F87314;   /* 行动橙: 唯一 CTA 色 */
  --orange-dark:#EA580C; /* 小字橙按钮文字 (对比度) */
  --wa:#25D366;       /* WhatsApp 绿, 仅 WA 入口 */
  --radius:12px;
  --shadow:0 1px 2px rgba(0,0,0,.06); /* 单级阴影, 禁多层 */
}
```

- 页面大面积是纸白 + 白卡片, **0 pastel, 0 彩色渐变卡片底**
- 橙色 = 唯一行动色, 每屏最多 1 个橙色主按钮
- 藏青仅用于权威区 (如数据带), 正文区一律纸白/白

### 标本签 (Specimen Label) — 产品元数据的呈现方式

每个产品的元数据用等宽字体 + 方括号标签, 像博物馆藏品标签:

```
[材質] PVC 防水    [起訂] 100 張    [交期] 5-7 天
```

font-family: ui-monospace, "SF Mono", Consolas, monospace; font-variant-numeric: tabular-nums;
13px, 字距 .04em, 墨色 70% 透明度。

### 字体

- 字体栈必须含中文: -apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans TC", sans-serif
- ⛔ 禁斜体中文
- 大标题: 800 字重, tight tracking (-0.02em), 关键词用橙色 <em>
- 价格/规格/数字: 等宽数字 tabular-nums

### 图标

52px 蓝底 (--blue) 白色线性 SVG 图标, 圆角 14px — 全页唯一图标形态。⛔ 禁 emoji 当图标。
