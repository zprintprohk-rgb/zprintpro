**根因推测（同上次）**：
- 页面的 `generateContactPageJsonLd` 函数引用了 `SITE_URL` 环境变量 `(typeof process !== 'undefined' && process.env?.NEXT_PUBLIC_SITE_URL)`，但在 Cloudflare Pages edge runtime 下可能返回 `undefined` 或在 streaming 渲染中抛出异常。
- 代码注释显示 `fix(contact-500)` 已做了一轮修复（合并 JsonLd 数组），但问题仍存在。

### 2.2 zh-HK 大小写路径不匹配（中优先级 — 新增发现）

| 路径 | 状态 | 说明 |
|------|------|------|
| https://zprintpro.com/zh-hk/（小写） | **200** ✅ | Next.js 动态路由 |
| https://zprintpro.com/zh-HK/（大写） | **404** ❌ | 路由区分大小写 |

**影响**：Google 可能已将大写 `zh-HK` 路径编入索引（hreflang 声明中用了 `zh-HK`）。如果 Googlebot 尝试访问大写路径会得到 404。

**建议**：在 middleware.js 或 next.config.js 中添加 `zh-HK` → `zh-hk` 的重定向逻辑。

### 2.3 联系页 hreflang / OG 元数据错误（中优先级 — 延续）

联系页 `generateMetadata` 中：
```typescript
alternates: {
  canonical: `${siteConfig.url}/${params.locale}/contact/`,
  languages: {
    "zh-HK": `${siteConfig.url}/contact/`,      // ❌ 缺少 /zh-hk/ 前缀
    "en": `${siteConfig.url}/en/contact/`,        // ✅
    "ja": `${siteConfig.url}/ja/contact/`,        // ✅
    "x-default": `${siteConfig.url}/zh-hk/contact/`, // ✅
  },
}
```
zh-HK 的 alternates 指向根路径 `/contact/` 而非 `/zh-hk/contact/`，这是 **hreflang 信号污染**。
