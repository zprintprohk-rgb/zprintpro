## 2. 根因分析

联系页500错误源于 Next.js 14.2 + Edge Runtime 环境下，连续3个独立 `<JsonLd>` 组件（每个使用 `dangerouslySetInnerHTML`）在 RSC streaming 末尾触发未捕获异常。主页使用 `data={[array]}` 数组形式（✅ 200），联系页使用3个独立 `<JsonLd>`（❌ 500）。

## 3. 修复措施（已提交到本地代码）

**文件**: `src/app/[locale]/contact/page.tsx` 第152行
**操作**: 将3个独立 `<JsonLd>` 调用合并为数组形式：
```tsx
// Before (production):
<JsonLd data={businessJsonLd} />
<JsonLd data={contactPageJsonLd} />
<JsonLd data={localBusinessJsonLd} />

// After (local fix):
<JsonLd data={[businessJsonLd, contactPageJsonLd, localBusinessJsonLd]} />
```
