## §5 转化漏斗: 电商交易全环节拆解

### §5.1 B2B 印刷电商漏斗基准

```
展示 → 点击 → 着陆 → 报价请求 → 报价单 → 支付 → 复购
         ↑        ↑          ↑         ↑
      CTR 病   速度/信任   度量断链   无数据
```

| 环节               | 基准                | ZprintPro 现状               |
| ---------------- | ----------------- | -------------------------- |
| 点击→询盘 (着陆页含即时报价) | 良性 3-5%, 优秀 8-15% | **无法度量** (Supabase key 阻塞) |
| 询盘→订单            | 良性 20%, 优秀 40%    | 无法度量                       |
| 订单→复购 (90 天)     | 印刷行业 25-35%       | 无数据                        |
| LCP              | ≤2.5s             | ✅ 14/15 达标 (CWV 基线已建)      |

### §5.2 竞品对标 (香港市场, 事实来源: e-print 招股书 + 公开资料)

* **e-print**: 赢在即時自助落單平台 + 18 门市信任网络 + 统一定价。客户平均订单 HK\$500-3,000

* **e-banner**: 网上即時報價 (省却等候报价时间) + 顺丰合作取货

* **PrintRainbow**: 专人跟进 + 100% 香港本地生产

* **ZprintPro 差异化**: 30 秒 AI 报价 (速度武器, 比 e-print 自助报价更快) + 跨境价格 (深圳实体成本优势) + 72h 全球交付。**报价速度是我们唯一能碾压 e-print 的点, 但目前没有埋点证明它在转化上生效**

### §5.3 结论: 最大杠杆不在"更多流量", 在"把已有展示变成询盘"

527 词 × 1,590 展示/快照期 = 如果 CTR 修到基准 + striking 61 词一半进首页, 点击可到 30-50/周, 按 3-5% 询盘转化 = **1-2.5 询盘/周**, 这就是北极星从 0 到可度量的第一步。而这一切的前提是 Supabase key 解锁。

## §8 站点地图提交问题 (K3 问)

**不需要手动重新提交。** 依据:

1. sitemap 每次构建自动 regen (8/25 04da70f 实证 6 文件 lastmod 自动更新)
2. T39 IndexNow 自动化 8/28 启动后, 新 URL 自动推送 Bing/索引
3. Google 对已在 GSC 注册的 sitemap-index.xml 会自动重抓, 重复提交不增加抓取配额 (Google 按站点权重分配抓取预算, 不按提交次数)

**建议一次性动作 (5 分钟, 真人操作)**:

1. GSC 后台 → Sitemaps → 确认 sitemap-index.xml 状态"成功" + 已发现 URL 数无异常下跌
2. 对本轮大改动的 \~10 个核心 URL (G1 index 页 + striking 第 1 梯队着陆页 + 月曆 SKU) 用 GSC "网址检查"工具逐个点"请求编入索引" — 这个对加速收录有真实效果, 比重交 sitemap 有效
3. 其余交给自动 regen + IndexNow + 自然抓取
