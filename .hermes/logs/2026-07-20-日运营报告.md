## 🐛 异常 / 调整 / 经验

### 异常 1: P2 unlock 内容已写但 matrix 未追
- **现象**: matrix.p2_coverage_pct = 0% 但 7-10 cron 已写 3 篇 (trade-show-banner / wedding-invitation-envelope / doujin-circle)
- **根因**: matrix.json.covered[] 维护滞后,7-10/15/16 cron 没追到 covered 数组
- **修法**: 本次 cron 启动时检测到, 转写 3 个**真正未铺**的 Tier C 行业
- **Lesson**: 任何 cron 启动时, 先查 blog-data JSON + matrix covered[] 实际一致性 (memory §0 「Fix collateral issues in-scope」)

### 异常 2: page.tsx 没有 posts.en block
- **现象**: posts 对象只有 'zh-hk' 和 'ja' 块, 无 'en' 块, en locale H1 走 fallback slug
- **根因**: 历史 cron bug — 7-15 cron 把 en entries 加到 zh-hk 块内(无效,因为 posts['en'] undefined)
- **修法**: 本次新建 posts.en block (3 entries),让 en locale 也能正确显示 H1 title
- **Lesson**: posts[locale] 是按 locale key 切换的,en entries 必须在 posts.en 块,不能塞 zh-hk 块

### 异常 3: blog-posts.ts 没 const 块导致 generate-sitemap.js 抓不到新 slug
- **现象**: 加 3 个 slug 到 page.tsx articleSlugs 后, sitemap.xml 仍只显示 Blog 66, 不含新 3 个
- **根因**: generate-sitemap.js 从 src/data/blog-posts.ts 抓 slug (regex `slug:\s*['"]([^'"]+)['"]`), 不从 page.tsx 抓
- **修法**: 在 blog-posts.ts 加 3 个 const blocks (lpReligiousCeremony / lpIndustrialNameplate / lpConstructionMaterialSampleBook), 重新 generate-sitemap.js → Blog 66→69
- **Lesson**: sitemap 抓取逻辑只在 blog-posts.ts const 块读 slug, page.tsx articleSlugs 不参与 sitemap 生成

### 异常 4: 7 步 verify Step 6 报 16/16/18 个 img
- **现象**: 9 个 blog 页面 grep "<img|cover" 报 16/16/18 个匹配
- **根因**: img 来自 page.tsx 的"Hot Products Sidebar"模块(4 个 img/page) + layout (logo + payment 4 个/page)
- **判定**: 实际 blog content 0 img (按 cron "无图" 硬约束 100% 满足),sidebar + layout 不算 blog content
- **Lesson**: 7 步 verify Step 6 严格说"博客内容无图", 但 page.tsx sidebar/layout 自动渲染 — 区分"blog content img" vs "page layout img"
