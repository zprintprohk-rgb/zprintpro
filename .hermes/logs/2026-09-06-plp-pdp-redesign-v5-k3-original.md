# ZprintPro PLP/PDP 重设计 — K3 战略军师原创方案 (v5, 2026-09-06)

> 不从千问底稿出发。从这门生意的第一性原理出发重做。
> 立场: PM + 资深 UI/UX + 高转化运营 + 数据分析四视角合一。

---

## §0 第一性原理: 这门生意卖的是什么

定制印刷电商的买家, 付款时**产品不存在**。他买的不是贴纸/盒子,
是「**一个看不见的结果的确定性**」。

所以页面的唯一任务 = 把不确定变成确定。每个买家脑内按固定顺序问 4 个问题:

| 顺序 | 买家的问题 | 页面必须给的答案 |
|------|-----------|----------------|
| Q1 | 你做不做得出我要的效果? | 材质/工艺/实拍品质证明 |
| Q2 | 多少钱? | 价格透明 + 量大省多少 |
| Q3 | 什么时候能拿到? | 交期承诺 |
| Q4 | 出问题怎么办? | 信任证据 + 风险逆转 |

**现有页面的根本病: 答案顺序被打乱了。** 品质证明埋在 tabs 里, 价格在但阶梯价值没可视化,
交期散在各处角落, 信任证据在页面最底部 — 买家在第 2 屏流失, 答案在第 8 屏。

重设计 = 把页面从「我们有什么的陈列馆」改成「买家 4 问的解答流」。

## §1 诊断 (独立判断, 截图 + grep 实测)

1. **叙事缺失**: 页面是陈列逻辑 (Tabs→表格→长文→FAQ→页底信任), 不是决策逻辑 → 滚动疲劳
2. **美术指导缺位**: pastel 色 + 红色爆炸贴 = 「打折杂货店」视觉语言; 一家印刷公司应该长什么样, 从来没人定义过 → 这是本次方案最大的增量点
3. **转化断点**: 报价动作只有 hero 1 个锚点, 8 屏滚动无回程票; 信任信号离决策点 6 屏远
4. **价值不可见**: 价格表是纯数据表, 「订 1000 张比 100 张每张省 52%」这种最有说服力的事实, 藏在表格里没人看见

## §2 美术指导 (Art Direction): 「印刷标本 / Print Specimen」

**核心概念: 把每个产品当作一件印刷标本、一份博物馆藏品档案来呈现。**

为什么是这个方向:
- 它是印刷行业**自己的语言** — 竞品 (Vistaprint/Sticker Mule/本地印刷网) 没人用, 一眼差异化
- 裁切标记、套准十字、标尺、出血线 = 潜意识信号「这家公司懂印刷」→ 信任
- 全部可用纯 CSS/SVG 实现, 零图片依赖, 零性能成本

具体规范:

| 元素 | 规范 |
|------|------|
| 视觉母题 | 裁切角标记 (crop marks) 做卡片四角装饰 / 套准十字做 section 分隔 / 细标尺刻度做价格轴 — 细线 1px, 墨色, 克制使用 |
| 底色 | 纸白 #FAFAF8 为主 (微暖纸感), 纯白卡片, 0 pastel 0 彩色底 |
| 墨色 | 正文近黑 #1E1E1C, 次要灰 #6B7280, 分隔线 #E5E7EB |
| 功能蓝 | #2873F5 只给链接/选中态/图标容器 |
| 行动橙 | #F87314 唯一 CTA 色, 每屏 ≤1 个橙色主按钮, 小字用 #EA580C |
| 藏青渐变 | #244780→#152649 仅页脚/数据带等权威区 |
| 标本签 | 产品元数据用等宽字体 tabular-nums: `[材質] PVC 防水` `[起訂] 100 張` `[交期] 5-7 天` — 像博物馆藏品标签 |
| 标题 | 大字重 800, tight tracking, 关键词橙色 em |
| 图标 | 52px 蓝底白线性 SVG, 全站唯一形态 |
| 阴影 | 单级 0 1px 2px rgba(0,0,0,.06), 禁多层 |

## §3 页面骨架

### PDP — 「4 问解答流」(冻结区: 顶栏/导航/面包屑/hero 左图右栏报价栈, 一字不动)

```
[冻结 hero]
   ↓
第 1 屏 · 先答 Q2+Q3 (钱和交期 — 买家最急的)
├─ 价格阶梯图 PriceLadder ★核心创新
│   数量-单价表 → 可视化递减阶梯条: 100張 $0.42 ▓▓▓▓▓ / 500張 $0.18 ▓▓▓ / 1000張 $0.20▓▓
│   旁边一句大数字: 「訂 1000 張, 每張省 52%」(从真实数据算, 不编造)
├─ 交期承诺卡: 标准 5-7 天 / 即日服務入口 (真实文案)
└─ 右栏 sticky 报价轨 StickyQuoteRail: 缩略价 + 橙「30 秒報價」+ 绿 WhatsApp
   (≥1024px 侧栏, 移动端底部悬浮条 — 全程回程票)
   ↓ (裁切标记分隔)
第 2-3 屏 · 再答 Q1 (做得出吗)
├─ 材质对比卡组 MaterialCompareCard: 实拍小图 + 克重横条 + 3 场景 chip + 价格区间
├─ 「工藝與品質」手风琴 (默认展开首项, 合并现有 tabs/长段重复内容, 单一权威版)
└─ 实拍特写带 (复用 public/images/factory/ 22 figure 资产)
   ↓
第 4 屏 · 答 Q4 (出问题怎么办)
├─ 信任证据条 TrustStrip: 6 信任点从页底前置到这里, 蓝底白图标 + 一句可验证证据
└─ FAQ 手风琴 (全页唯一渲染源, FAQPage schema 不动)
   ↓
第 5 屏 · 证据与延伸
├─ 相关产品: 标本签式卡片, 去全部爆炸贴
├─ SEO 长文折叠进「採購指南 (展開閱讀)」— 搜索引擎可读, 用户不被迫读
└─ 页底品牌陈述 + 单一大 CTA (现状保留)
```

### PLP — 「选购向导」而非「商品货架」(冻结: banner + 左导航)

印刷品类目页的真实任务: 买家不知道选哪种材质/工艺, **帮他选对 = 最好的转化器**。

```
[冻结 banner]
   ↓
第 1 屏 · 「30 秒找到你的規格」决策卡 ★PLP 核心创新
   用途 (3-4 场景 chip) → 推荐材质 → 数量区间 → 直达对应 SKU 锚点
   (视觉层重排, 链接全部指向已有 SKU, 零新内容)
   ↓
第 2 屏 · 标本签式产品网格
   卡片 = 图 + 等宽字体元数据行 [材質][起訂][交期] + 价格 + 单 CTA
   去 pastel 图标容器 / 去爆炸贴 / 去双按钮
   ↓
第 3 屏 · 行业场景区 (白底细边蓝图标, 删 amber/rose 渐变)
   ↓
第 4 屏 · 选购知识区 (SEO 内容陈列升级: FAQ 手风琴 / 规格表斑马纹深蓝表头 / 文案逐字不动)
```

## §6 验收标准

| 项 | 过线标准 |
|----|---------|

| 去重 | FAQ 全页 1 次, SEO 长文折叠 |
| 爆炸贴 | 全站仅 hero 冻结区 1 处 |
| 内容 | git diff src/data/ messages/ 为空, schema 不动 |
| 容器 | 1320px 居中, 移动 375px 正常 |

## §7 北极星与数据验收

- 北极星: 询盘数 (报价轨点击 + WhatsApp 点击 + 表单提交, 008 台账 src 归因)
- 过程指标: 试点页 CTR (GSC 7 天对比, 基线 0.54% → 目标 1.5%+)、PDP 平均排名 (守护线: 跌 >5 位即回滚)
- 设计为「询价动作」服务, 不为「好看」服务 — 好看但 CTR/询盘不涨 = 回滚

## §8 与千问方案的关系 (诚实声明)

骨架层面 (去重/信任前置/sticky 报价轨) 与千问殊途同归 — 这些是 CRO 行业常识, 不为不同而不同。
本方案的真正增量, 千问文档里没有的:
1. **「4 问解答流」决策叙事** — 重排的逻辑依据, 不是凭感觉排
2. **「印刷标本」美术指导** — 行业自有视觉语言, 解决「没有设计美感」的根
3. **PriceLadder 价格阶梯可视化** — 把最有说服力的省钱事实从表格里解放出来
4. **PLP「30 秒选购向导」** — 类目页从货架变导购

千问方案做完 = 一个干净的 B2B 站; 本方案做完 = 一眼专业的印刷行家。

# v6 增补条款 (2026-09-07, K3 + CEO/PM/UX/运营/数据 五视角复审后追加)

> 以下条款在 v5 原文基础上追加, 冲突处以 v6 为准。v5 的「4 问解答流」叙事、「印刷标本」美术指导、
> PriceLadder、SpecFinder、StickyQuoteRail、TrustStrip 全部保留——它们是 CRO 增量, 不动。
> v6 只修两件事: **冻结区范围** 与 **内容资产红线**。

## §0 战略定调: 为什么不能「为干净而删内容」

v5 执行稿把 PDP 中文内容砍掉 49% (3390→1734 中文字)、PLP 砍掉 72% (4324→1213 中文字),
H2/H3 从 20/33 个降到 6/4 个, AEO 问句从 14/23 个降到 5/8 个。10 个关键词归零
(零售/燙銀/專色/同人/餐飲/低溫/冷凍/免運/擊凸/色差), 18 个核心词腰斩
(智印港/貼紙印刷/不干膠/ZprintPro/香港印刷/小批量/ISO 9001/色彩管理/客戶/活動/UV/燙金等)。

这门生意的北极星 = **重点带钱词三语言霸屏 + 进 AEO/GEO 推荐页 + 询盘 ROI**。
「干净」是手段不是目标; 砍掉内容换来的干净, 是拿搜索可见性祭旗。
**v6 定调: 页面结构按 4 问流重排, 但内容资产一个字不许净减——只能「重排/合并/重述」, 不能「删除」。**

## §1 冻结区重定义 (覆盖 v5 §3 与 prompt 文件「冻结区」节)

| 页面 | v5 旧冻结区 | v6 新冻结区 (红框标注为准) |
|------|------------|--------------------------|
| PDP | 顶栏/导航/面包屑/hero 左图右栏报价栈/信任徽章行 | **以上全部 + 页脚整区** (页脚含 NAP 公司名/地址/电话/邮箱/营业时间 + 關於我們/產品中心/幫助中心/客戶服務 四列链接 = GEO 本地实体信号 + 全站内链资产, 一字不动) |
| PLP | banner 区 + 左侧类目导航 | **以上全部 + 页脚整区 + 左侧栏整列** (含「產品分類」15 个分类项及计数、快速詢價块、企業批量訂寶卡含 QR 码与「15,000+ 客戶」文案——这是全站分类内链枢纽 + 信任资产, 一字不动) |

冻结区图标与样式按线上形态复刻 (顶栏电话/邮箱用 lucide SVG, 不用 emoji)。
「你只设计冻结区以下的内容区」改为: **只设计主内容流区, 冻结区逐字照抄线上版**。

## §2 内容资产红线 (新增, 最高优先级, 命中即打回)

1. **中文字符量红线**: 改版后页面中文字符数 ≥ 线上现版的 95% (允许合并去重, 不允许净减)。
   基线: PDP 防水貼紙页 = 3390 中文字; PLP 貼紙类目页 = 4324 中文字 (2026-09-07 快照实测)。
2. **标题骨架红线**: H2/H3 数量 ≥ 现版 90%, 且以下带钱词区块标题必须保留原词
   (可重排顺序, 不可删除): 「常見問題」「材質與紙張對比/材質工藝詳解」「相關產品」
   「為何選擇智印港」「產品詳情」「印刷工藝說明」(PDP); 「產品分類」「3 個直接答案」
   「渠道比較」「落單流程」「更多常見問題」「核心競爭優勢」「技術參數詳解」「服務行業與應用場景」(PLP)。
3. **AEO 问句红线**: FAQ 问句总数 ≥ 现版, 且必须含现版全部带钱问句
   (PDP: 最低訂量/防水 vs PVC 分別/即日取貨/燙金成本/九龍送貨/檔案規格/材質選擇;
   PLP: 1000 張幾錢/最快幾日有貨/最受歡迎尺寸/MOQ/小批量接不接/付款方式/轉數快/形狀/防水真防水嗎/每張印不同內容/背膠殘膠/戶外維持多久/最快取貨/港島九龍新界送貨)。
4. **关键词覆盖红线**: 以下现版高频词在新版出现次数不得腰斩 (现版 ≥3 次 → 新版 ≥1/2):
   智印港/貼紙印刷/防水/透明貼紙/不干膠/小批量/燙金/模切/UV/ISO 9001/色彩管理/客戶/活動/WhatsApp/全球/報價。
   以下现版长尾词新版必须 ≥1 次: 零售/燙銀/專色/同人/餐飲/低溫/冷凍/免運/擊凸/色差/貼紙訂製/香港印刷/ZprintPro。
5. **结构化区块红线 (PLP)**: 线上现版的以下区块 v6 必须保留等价呈现 (可换视觉形态, 不可删):
   - 「3 個直接答案」卡 (1000 張幾錢/最快幾日/最受歡迎尺寸) — AEO 精选摘要头号候选
   - 「香港貼紙印刷渠道比較」表 (網上平台/實體店/智印港 三列对比) — 高商业意图词锚点
   - 「6 步落單流程」步骤条 — 转化漏斗说明 + HowTo schema 候选
   - 「核心競爭優勢/材質工藝詳解/特殊加工選項/技術參數詳解/本地化服務節點」SEO 主区块
   - 「服務行業與應用場景」场景段落 (餐飲外賣/美妝樽身/零售精品/寵物食品/文創 IP)
   - 数据徽章带 (4820+ 累計訂單/2.3 天平均出貨/100 張起 MOQ/9 種材質)
6. **NAP 一致性红线 (GEO)**: 公司名「智印港 (ZprintPro)/彩耀印刷」、地址「香港九龍新蒲崗大有街3號萬廣大廈15樓C室」、
   電話「+86 198 8085 1334」、WhatsApp、邮箱在页脚与品牌陈述区逐字一致, 与 GMB/官网其他页面完全一致。
7. **「SEO 长文折叠进 details」条款作废**: v5 允许把 SEO 长文收进 <details>「採購指南」——
   v6 改为: 长文可以「分区重排 + 视觉降级 (小字/浅灰/收起次要段落)」, 但正文区必须保留
   带钱词密度足够的可见文本; details 只许装「次要的重复性说明」, 不许装含目标关键词的段落。

## §3 AEO/GEO 新增要求 (v5 没有, v6 补齐)

- **实体一致性**: 品牌名「智印港」「ZprintPro」「彩耀印刷」在全页出现 ≥3 次且与页脚 NAP 一致;
  香港地名 (九龍/新蒲崗/港島/新界) 保留, 强化 GEO 本地实体识别。
