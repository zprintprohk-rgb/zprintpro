# V25.6 生图评分指令 v3（2026-08-24 更新）

> 变更人：唐总 ｜ 在 v2（动作手部达标）基础上新增：**全视图最多一只手 + 无清晰人脸/头部 + DJ 封面必须鲜艳靓丽**。

## 一、手部规则（v3 定稿）

| 规则 | 内容 |
|---|---|
| 最多一只手 | 画面允许出现手部，但**最多 1 只**；出现 2 只手同框 → 扣分 |
| 手部质量 | 手指数量正确（5 指）、关节自然、动作合理（书写/持握/递出/翻阅）→ 达标 |
| 手部出现不扣分 | 只要质量达标，DETAIL/HERO/VARIETY/MULTI 出现 1 只动作手均不扣分 |
| 畸形才扣 | 多指/缺指/融合/关节扭曲/动作不合理 → 扣分 |

## 二、人脸规则（v3 新增）

| 规则 | 内容 |
|---|---|
| 无清晰人脸 | 画面不允许出现清晰人脸/头部 |
| 背景人物 | 背景人物必须重度虚化、不可辨认（如漫展人群、家宴宾客） |
| 构图取向 | 手部+产品构图优先，人物只以虚化背景出现 |

## 三、DJ-001 同人志色彩规则（v3 新增）

- 封面必须**鲜艳靓丽**：高饱和、明亮糖果色、高调光（vivid saturated / bright candy accents / high-key lighting）
- 禁压抑灰暗：NEGATIVE 含 `no dark gloomy colors, no muted desaturated tones`
- 评分维度 4 明确：色彩压抑灰暗 → 扣分

## 四、评分维度（v3 全视图通用）

1. 场景/构图是否符合视图定位
2. 材质/工艺细节真实度（按 SKU 差异化：烫金/纸纹/绳编/银箔/装订）
3. 文字无乱码（含无伪中文）
4. 色彩符合品类色板（DJ 要求鲜艳靓丽）
5. 手部（如有）：最多 1 只、自然无畸形、动作到位；无清晰人脸/头部
