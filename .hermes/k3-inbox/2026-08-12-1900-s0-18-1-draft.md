# §0.18.1 308 跟 301 SEO 权重传递等价 (2026-08-12 19:00 K3 拍板, 跨项目 P0)

## §0.18.1.1 教训 (K3 8/12 19:00 拍板)

**308 Permanent Redirect 跟 301 Moved Permanently 在 SEO 权重传递上完全等价**。Google 2016 年起明确声明 308 是可接受的永久重定向, 权重传递 100%。

**反例 (zprintpro 8/12 18:41 复盘)**:
- 7/22 baseline 5 路径级规则用 301 测 5/5 PASS
- 8/12 9de2479 cron 触发 next-intl 8.x 升级, 自动改用 308
- 8/12 实测 4/5 FAIL = 实际 4 条 308 + 1 条 301, 仍 5/5 永久重定向
- ❌ 误判: "301 退化" = 测试口径变了 (测 301 vs 实际 308), 不是 SEO 效果变

**事故背书 (2026-08-12)**:
- 7/22 K3 拍板 §0.18 4 步 SOP (curl 200 + 禁止兜底 + 禁止自指向 + m3u8 用 410)
- 8/12 18:41 复盘测脚本, 4/5 FAIL, 误判为 P0
- M3 19:00 调查: 实际是 next-intl 8.x 升级, 4 条 308 + 1 条 301, SEO 等价
- K3 19:00 拍板 "按推荐 A 方案" = 接受 308, 0 修复 commit

## §0.18.1.3 判断 SOP (任何重定向测试 commit 实施前自查)

1. `curl -I <url>` 看 status code
2. **接受 301 跟 308** (都是永久重定向, SEO 权重 100% 传递)
3. 接受 302 跟 307 (临时重定向, SEO 权重 0%, 不算 redirect 成功)
4. 检查 location header 是否指向正确目标 (无覆盖多 locale 活路径, 无自指向)
5. m3u8 等永久删除用 410 (CF Edge Rule Ruleset), 不用 301/308
