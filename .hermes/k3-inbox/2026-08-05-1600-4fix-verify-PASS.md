## 六、Memory 跨项目教训 (R6 协议升级)

| 教训 | 跨项目可复用 |
|------|-------------|
| **Python 模拟 ≠ Node.js SSR** | 任何"修复杂业务逻辑" commit 必跑 live 验证 ≥ 12 URL, Python 模拟 100% PASS 也不够 |
| **DEBUG marker scope 漏洞** | 任何 marker 引用必须保证 引用变量在所有分支定义, 或 marker 本身要 try/catch |
| **cron auto-commit 风险** | gsc-feedback-loop 等 cron auto-commit 改 page.tsx 风险高, 应让 M3 显式 commit + 拍板 (cron 改 .hermes/matrix.json OK, 改 src/ 危险) |
| **hermes 临时文件 .gitignore** | .hermes/{tmp,scripts}/* 已 ignore, 但其他 .hermes/*.txt/*.py 没 ignore, 手动管理 |
| **Python regex 处理多引号字符串** | 用 backreference `(["'])((?:[^'\"\\]|\\.)*?)\\2` 区分单/双引号, 跑完必跑 TypeScript build 验证 syntax |
