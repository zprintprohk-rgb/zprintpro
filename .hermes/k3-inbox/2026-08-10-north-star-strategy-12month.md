## §1 北极星拆解：$20k/月 的数学模型

> 目标不是「流量大」，是「营收 $20k」。先反推订单结构，再反推流量需求。

### 1.1 营收反推 (推演，基于印刷跨境 AOV 常识)

| 假设项 | 取值 | 说明 |
|---|---|---|
| 混合客单 AOV | **$120-180** | C 端小单 $30-80 / B 端中小单 $150-500 混合；取中值 $150 |
| $20k 所需订单 | **≈ 133 单/月 ≈ 4.4 单/天** | 20000 ÷ 150 |
| 自然流量转化率 | 1-2% | 印刷定制类电商常见区间 |
| 所需日均 organic UV | **220-440/天** | 4.4 ÷ (1~2%) |
| 所需月 organic UV | **≈ 6,600-13,200/月** | |
| **当前实际** | **18 clicks/月** | GSC 8/9 |
| **缺口** | **≈ 370-730 倍** | 这就是为什么纯 SEO 不够 |

**结论 (事实+推演)**: 单靠自然搜索点击 370 倍缺口，12 个月内仅靠 SEO 排名**不可达**。必须叠加：
- **高 AOV B2B 单** (把 AOV 从 $150 拉到 $400+，订单数需求降到 ~50 单/月)
- **复购/订阅** (1 个餐飲连锁客户 = 每月稳定 5-10 单，LTV 远超一次性流量)
- **GEO AI 引用带来的直接流量与品牌词** (不依赖排名点击，见 §3.2)

### 1.2 三引擎营收分担 (M12 目标态，推演；K3 8/10 拍板不做付费)

| 引擎 | M12 月营收占比 | 金额 | 依赖 |
|---|---|---|---|
| B2B 复购/订阅 (Tier A 行业) | **50%** | $10,000 | 客户成功 + 复购 SOP |
| SEO 自然 (zh-hk 收割 + en/ja 爬坡) | **35%** | $7,000 | 核心词进 top10 |
| GEO AI 引用 (品牌词 + 直接流量) | **15%** | $3,000 | 实体一致性 + 结构化数据 |
| **合计** | 100% | **$20,000** | |

> ⚠️ 关键判断：**B2B 复购是主引擎，不是 SEO**。SEO/GEO 是获客入口，把客户沉淀成复购才是 $20k 的真路径。这与 master-directive「SEO+GEO+付费+B2B 多引擎」一致，但**明确 B2B 权重最高，且付费引擎已移除**。

### 1.3 为什么不做付费投放（利润率测算，K3 8/10 拍板）

> 详细模型见 `.hermes/reports/2026-08-10-ROAS利润测算.xlsx`（可调参数）。核心是每 $100 营收的账：

| 项 | 付费渠道 (ROAS 2.5) | 自然流量 (SEO/GEO) |
|---|---|---|
| 毛利率 | 50% | 50% |
| 跨境物流 + 支付手续费 | -13% | -13% |
| 广告前贡献率 | 37% | 37% |
| 广告费 (1/ROAS=1/2.5) | **-40%** | ≈0 |
| **净利润率** | **-3%（每单亏）** | **+37%** |

- ROAS 2.5 时广告费占营收 40%，高于贡献率 37% → **卖得越多亏得越多**
- 盈亏平衡需 ROAS≥2.7；要赚 10% 净利需 ROAS≥3.7，印刷电商极少能稳定做到
- SEO/GEO 内容资产可长期复用、边际成本趋零；广告费是每单重复支出的沉没成本
- **结论**：在营收未起量、真实毛利率未校准前，付费投放既无必要也无利润空间，专注 SEO+GEO+B2B 复购
