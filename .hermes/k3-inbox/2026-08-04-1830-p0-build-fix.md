## 🛠 修复 (66b922d commit 18:30)

### 修法 1: popularity.ts fs/path client-side skip + dynamic require
```ts
// 1) client side 完全跳过
if (typeof window !== 'undefined') {
  cachedPopularity = weightScoreFallback();
  return cachedPopularity;
}

// 2) server side 用 Function('return require')() 强制运行时解析, 绕开 webpack 静态分析
const dynamicRequire = new Function('name', 'return require(name)') as any;
const fs = dynamicRequire('fs') as typeof import('fs');
const path = dynamicRequire('path') as typeof import('path');
```

注意: `/* webpackIgnore: true */` 注释方案失败, 因为 `typeof import('fs')` 这种 type annotation 仍触发 webpack 静态分析。
