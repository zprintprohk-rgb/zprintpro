### 2.5 本節結論（三個病灶，勿混為一談）

1. **位置好但零點擊 = 摘要/標題問題（7 條 / 480 展示）**：`食品包裝印刷`（145 展示、位置 6.65、0 點擊）是最刺眼的一條——位置在首頁第一屏，28 天 145 次被看到、0 次被點。同類：`small batch sticker printing`（69 / 6.61）、`small batch stickers`（40 / 5.53）、`a6 尺寸`（97 / 8.86）、`大信封`（45 / 4.42）、`小冊子印刷`（48 / 10.04）、`邊度有紙袋買`（36 / 7.44）。這批是**改 title / meta description 就能直接變現**的，不等排名。
2. **位置差但展示大 = 排名問題**：`海報印刷`（174 展示 / 位置 22.57 / 0 點擊）、`貼紙印刷`（165 / 27.28 / 0）、`印海報`（143 / 23.74 / 0）、`宣傳單張`（129 / 36.33 / 0）、`宣傳單張印刷`（127 / 32.09 / 0）、`月曆印刷`（126 / 20.33 / 0）。這些是第一/第二主戰場的**核心大詞**，合計 864 次展示、0 點擊——不是摘要問題，是根本不在第一頁。
3. **日文站全帶零點擊**：ja 語系 73 條查詢 / 553 次展示 / **0 次點擊**（CTR 0.00%），含 `コミケ 印刷`（94 展示 / 位置 29.61 / 0 點擊）這種高展示詞。ja 是三個語系中唯一 28 天零點擊的。
