## Phase 2 · D2 轻量索引 (60 min, D1 未消重时强制执行; D1 成功时作为加固可选)

### Step 2.1 新建 `src/data/products-index.ts` (Write 工具, UTF-8)

只导出共享组件实际用到的轻字段 (K3 已核对 ProductCard / RelatedProducts 字段用量):

```ts
// 轻量产品索引 — 供 layout 链 / 列表卡片 / 搜索使用
// 全量字段 (longDescription/specs/features) 只在 product/category 路由 import @/data/products
import { products } from '@/data/products';   // 若 products 导出名为别的, 以实际为准

export interface ProductIndexEntry {
  id: string; sku_code: string; slug: string;
  category: string; category_slug: string;
  name: string; nameEn: string; nameJa: string; title_zh: string;
  price_range: string; basePrice: number; basePrice_en?: number; basePrice_ja?: number;
  weight_score: number; isHot: boolean; isNew: boolean;
  minQuantity: number; turnaround?: string; images: string[];
}

export const productsIndex: ProductIndexEntry[] = products.map((p) => ({
  id: p.id, sku_code: p.sku_code, slug: p.slug,
  category: p.category, category_slug: p.category_slug,
  name: p.name, nameEn: p.nameEn, nameJa: p.nameJa, title_zh: p.title_zh,
  price_range: p.price_range, basePrice: p.basePrice,
  basePrice_en: p.basePrice_en, basePrice_ja: p.basePrice_ja,
  weight_score: p.weight_score, isHot: p.isHot, isNew: p.isNew,
  minQuantity: p.minQuantity, turnaround: p.turnaround, images: p.images,
}));
```

⚠️ 注意: 此写法运行时仍引用 products 全量模块 — **仅在 webpack tree-shake 能把 longDescription 等字段摇掉时才有效**。更稳妥做法: 把 `products` 数组本身拆文件 (见 Step 2.3 判定)。

### Step 2.2 切换共享组件 import (Edit 工具逐文件)

| `src/lib/seo.ts` / `src/lib/popularity.ts` / `src/lib/product-image.ts` | 逐个看用到哪些字段, 轻字段则切换 |

**不许动**: `product/[slug]/page.tsx` / `category/[slug]/page.tsx` / `app/api/*` — 它们需要全量字段, 保留 `@/data/products`。

每改 1 文件跑 `npx tsc --noEmit`, 0 错才改下一个。

### Step 2.3 重 build 判定


- ✅ 若 tree-shake 生效 (大 chunk 明显缩小 或 双副本内容变轻) → 记录数字, 进 Phase 3
