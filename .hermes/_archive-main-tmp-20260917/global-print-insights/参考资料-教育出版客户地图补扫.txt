## 1. 书籍品类（个人出书 / 企业年鉴 / 内部书籍）

### 1.1 品类定义与常见规格

**定义**：以"本/册"为单位的成册印刷品，装订成书。典型流向：个人作者自费印制（回忆录、文集、诗集、小说）、企业机构内部书籍（年鉴、周年纪念册、员工手册、企业文化手册）、机构教材/成果集。

| 规格维度 | 常见配置 | 说明 |
|---|---|---|
| 开本/尺寸 | 32开（130×185mm，近似 A5）、16开（185×260mm，近似 A4）、大16开（210×285mm） | 个人文集多用32开；年鉴/画册多用正16开或大16开 |
| 内页纸张 | 黑白：70–80g 胶版纸/轻型纸；彩印：105–128g 铜版纸/哑粉纸 | 文字类书籍用胶版纸更护眼、更轻；画册类用铜版纸 |
| 封面纸张/工艺 | 200–300g 铜版纸 + 覆膜（哑膜/亮膜），可选烫金/银、UV、压纹 | 封面建议 180g 以上，成品更挺括（参见装订科普） |
| 装订方式 | 骑马钉（约≤64页）、无线胶装（72页以上常用）、锁线胶装（耐翻、可摊平）、精装硬壳（年鉴/纪念册） | 相对成本：无线胶装约为骑马钉 ×1.26、锁线胶装 ×1.52、精装 ×2.34（港台同业公开比较，趋势参考） |
| 装订附加费 | 胶装 2–5 元/本、锁线胶装 3–7 元/本（单本口径） | 来源：知乎《画册印刷单本成本》拆解文 |
| 常用印量 | 个人出书 100–1,000 册；年鉴/纪念册 300–3,000 册；员工手册 100–2,000 册 | 胶印经济起印量约500册，数码印刷1册起（行业文章） |
| 参考单价 | 自费出书 500 册平装胶订（带腰封/UV/哑膜）≈4,500 元（约9元/本，知乎专栏）；1,000 册简装中等质量约 1–2 万元（腾讯作家专区）；单色单本 5–30 元、彩色 7–200 元（按工艺差异大） | 以上为印刷环节口径，不含书号/编审 |

### 2.3 获客触点提示

- **渠道**：①招标端——政府采购网/公共资源交易平台/学校官网"印刷服务"公告（学报、校报、教育局印刷服务逢采必招，可见必联网"印刷招标采购频道"长期滚动）；②关系端——学校宣传处/学报编辑部与本地印刷厂长年合作，靠续约与转介绍；③组织端——商会秘书处、行业协会（会刊年度排期稳定）；④平台端——1688/淘宝"期刊杂志印刷"店铺；⑤资质门槛——具备"出版物印刷资质"是承接学报/期刊类的前提，建议作为差异化卖点。
- **时间窗口**：招标公告全年滚动，其中学报类多在**刊期前1–2月**（如6月询价、9月出刊）；内刊/会刊集中在**年末年初**；注意9–10月排期紧张。
- **决策人角色**：学校——宣传处/团委老师（校刊）、学报编辑部主任（学报）、分管副校长（签批）；企业——品牌/文化专员、行政经理；商会/协会——秘书长、秘书处干事；招标项目——采购中心+评标专家。

## 3. 作业本品类（中小学 / 幼儿园常规作业本）

### 3.1 品类定义与常见规格

**定义**：义务教育阶段学校按学期统一配发或学生自购的标准化簿册（练习本、数学本、英语本、作文本、田字格/拼音本等），以及幼儿园描红本、绘画本、操作材料本等。属**学期制、高频、标准品**类印刷需求，主流渠道为政府采购（多地免费发放）。

| 规格维度 | 常见配置 | 说明 |
|---|---|---|
| 尺寸/开本 | 小学：32开（130×185mm）；中学：16开（185×260mm）；幼儿园/低年级：24开、28开等小开本 | 团体标准与工厂公开资料一致口径 |
| 内页 | 70g 书写纸/双胶纸（优质用70g及以上，护眼黄纸流行）；单本20–50页 | 学校招标示例：内页70g双胶纸、50页、16开 |
| 封面 | 128–130g 铜版纸（彩印、可过哑膜）或牛皮纸；可印校名/校徽 | 招标示例：封面128g彩色、封二封三过哑膜；另有130g铜版纸外皮 |
| 内页格式 | 田字格、方格、横线、四线三格（英语）、拼音格、点阵、空白等 | 工厂公开产品线；幼儿园以描红/绘画格式为主 |
| 装订 | 骑马钉/缠背胶装（薄本为主） | 单本薄，成本以"分"计 |
| 参考价格 | 政府/学校采购端：0.48–1.26 元/本（详见场景表）；1688批发端低至0.34元/本（500本/箱） | 传统零售渠道单本1.5元以上 |

**政策背景（影响决策链）**：全国多地自2008年起陆续将义务教育阶段作业本纳入政府统一采购、免费发放（上海、青岛等先行；2026年福州、晋安、岳池等地仍在按学年采购）。这决定了**区县级教育局是最大买家**，学校端则负责补充采购与验货。学校采购人须注意"代收费/免费发放"合规口径，供应商报价与结算走政府采购流程。

### 3.3 获客触点提示

- **渠道**：①招标端——中国政府采购网（ccgp）、各省市公共资源交易中心、教育局官网（"免费作业本采购"公告固定出现，如福州教育局2026年3月征集方案、晋安区6月公示结果）；②学校端——开学前1–2个月各校官网/后勤部门询价；③平台端——1688文具批发带（支持小批量定制+印刷）；④渠道端——文具经销商、校园超市（承接家委会团购）。
- **时间窗口**：招标公告以**3–6月**最密集；交付备货旺季**6–8月**（秋季）与**12–1月**（春季）；开学后2周为补单窗口。
- **决策人角色**：教育局——采购中心/计财科负责人；学校——总务处（后勤科）主任、分管副校长；幼儿园——园长/保教主任；教培——校长/教务。**印刷供应商资质与服务（配送分拣、按校打包）是评标关键项**。

### 5.4 合规注意事项汇总

1. **准印证制度**：无刊号的内部书籍/校刊/内刊/会刊，委印单位须取得《内部资料性出版物准印证》，印刷企业必须验证准印证原件并收存复印件（《印刷业管理条例》第二十条、《内部资料性出版物管理办法》）。
2. **字样限制**：内部资料不得使用"××报""××刊""××杂志"等字样，必须注明"内部资料，免费交流"及准印证编号（多地新闻出版行政部门办事指南）。
3. **属地印刷**：内部资料须在编印单位所在省级行政区域内的出版物印刷企业印刷（管理办法第十六条）。
4. **资质要求**：正式出版物（学报、期刊、图书）承印需"出版物印刷经营资质"；学校招标常设为资格条件。
5. **教培类**：注意"双减"政策背景下学科类培训宣传物料合规性（不承诺提分、不渲染焦虑等宣传规范），承接机构物料时不参与文案违规设计。
6. **个人信息**：回忆录、同学录、通讯录类产品涉及个人信息，打印文件规范保管、交付后销毁中间文件。
