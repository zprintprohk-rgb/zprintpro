## 🆘 v3 双站挽救方案 (2026-07-17 16:30 · user 确认老站是自家资产后)

### 先纠正一个认知:不存在"GSC 惩罚机制"

GSC 只是数据面板,不惩罚任何站点。你观察到的是 **Google 排名系统的关键词自相残杀 (cannibalization) + 品牌实体混淆**:两个相似域名、相似内容、抢同一批词,Google 不知道该推谁,就把票分给两边 — 两边都进不了首页。"隔离"(删品牌词、互称竞品)治不了这个病,因为病根在**关键词车道重叠**,不在品牌提及。

新站上线初期"最多 15 展示"也不是惩罚,是新域名正常爬坡。数据为证:新站现在日均展示已从 162 → 246 (+52%),点击 +43%,在涨,只是还没积累够。

### 自相残杀实锤 (两站 GSC 交集分析)

| 证据                  | 数字                                                                         |
| ------------------- | -------------------------------------------------------------------------- |
| 两站重叠查询              | **176 个**                                                                  |
| 互相残杀区 (两站排名都在 8-60) | **141 个词**                                                                 |
| 残杀区合计展示             | 老站 9,089 + 新站 5,952 = **15,041 次/季度,点击≈0**                                 |
| 残杀词构成               | 几乎全部是 B2B 钱词 (紙袋/包裝盒/貼紙/宣傳單張),本地急件词只占 6%                                   |
| 新站排名已反超老站的词         | 15 个 (紙袋印刷 19.7 vs 29.3 / 食品包裝印刷 38.6 vs 57.1 / 印紙袋 27.1 vs 32.9…) — 移交阻力小 |
| 老站独有词 (新站零覆盖)       | 322 个 (印袋 347 / 紙袋設計 314 / 購物袋印刷 165 / 環保袋印刷 161…) — 全是钱词变体                |

**解读**: 15,000 次/季度的高意向展示,因为分票,两站合计拿到不到 10 个点击。合并到一个域名后,这批词进入 5-15 位的概率很高,按 3-5% CTR = 每季度 450-750 个免费高意向点击 ≈ **每天 5-8 个询盘级访问**,这是全站最大的单一增长杠杆,且不需要写一篇新内容。

产出文件: `overlap-keywords.csv` (176 重叠词 + 车道标注)、`old-only-keywords.csv` (322 个老站独有词 = 新站内容缺口清单)。

### 我的判断:不做全站 301,做"分车道 + B2B 选择性 301"

全站 301 的问题:会把"旺角即日海报 50-80 元"的赔本零售需求一起倒进新站漏斗,人工被微单拖死;同时杀死老站仍在产的 B2B 订单。维持现状的问题:141 个词继续分票,新站永远起不来。

**正确解 = 按"生意价值"切车道,不按域名切:**

| 车道            | 词/页                                         | 归属                       | 动作                                                             |
| ------------- | ------------------------------------------- | ------------------------ | -------------------------------------------------------------- |
| **跨境 B2B 车道** | 紙袋訂製/包裝盒印刷/貼紙印刷/宣傳單張印刷/紙盒訂製…(141 残杀词中的 94%) | **新站 zprintpro.com**     | 老站对应类目+产品 .html 页 **逐条 301** 到新站 /zh-hk/category\|product/ 对应页 |
| **香港本地急件车道**  | 即日/旺角/銅鑼灣/學校/論文/證書/過膠/24小時                  | **老站 z-printpro.com 保留** | 品牌明确为"智印港 = 香港本地急件",但改造商业模式 (见下)                               |

### 老站本地车道的商业模式改造 (解决"海报单不赚钱")

你的账是对的: 单张海报 50-80 元 - 快递 30 - 人工咨询 15-30 分钟 - 制作打包 = **负毛利**。三种处置,按推荐顺序:

1. **微单自助化 (首选)**: 老站微单全部改为线上固定价 + 线上付款 + 自助上传文件,**零人工介入**,设起送门槛 (如快递单 HK\$150 起或仅限自取)。不赚钱的单要么变自动流水,要么自然筛掉。人工只接 B2B 询盘。
2. **价格地板**: 单张海报连快递 HK\$120-150 起 (把快递和人工明码标价进价格),愿意付的客户自然覆盖成本。
3. **顺水推舟做 B2B 跳板**: 老站每个页面加一条横幅 "批量訂製 / 跨境包裝 → 智印雲 zprintpro.com" — 把零售流量里的 B2B 意向者导给新站 (人工询盘),这是老站对 \$50K 目标的最大贡献方式。

### B. intuan.com 报价系统分解 (为什么它"牛")

抓取 intuan.com 首页 + 产品页结构 + 同源系统站点 (现代印 xiandaiyin 专版手提袋报价器),其报价系统 6 个可复制的支柱:

1. **双轨制产品线**: 合版 (拼版: 固定规格、便宜、出货快) vs 专版 (独立开版: 尺寸/材质/工艺全自由)。*对我们的映射*: 小单 (100-500) 走"标准款固定价" (类合版),大单 (1000+) 走"专版定制报价"。
2. **参数逐项分解报价**: 成品尺寸 (宽/高/厚自定义) → 印面/印色/纸张/克重 → 后道工艺逐项加价 (覆膜/烫金/烫银/UV/压纹/过油/穿绳/糊合/模切/击凹) → 包装方式 → 数量 → 实时总价。**每个参数的价格贡献透明**,用户自己玩参数就理解"钱花在哪"。
3. **数量档单价跳水**: 开机费固定 + 纸张印工随量 → 单价随数量陡降,用价格表引导客户"加到下一档" — 印刷电商提 AOV 的核心机制。
4. **打包锚点价**: "铜版纸名片 5 盒 30 元" "数码画册 彩色 2.5 分/P" — 一句话降低决策成本。
5. **交易直播滚动条**: 首页实时滚动"订单 260\*\*\*\*7563 合版宣传单 18:03" — 社会证明。
6. **专业信任件**: 刀版下载 / 印前须知 / 质量问题 7 天退换 / 1 对 1 客服。

**e-print.com.hk 对标锚点** (zh-hk 市场零售价基准): 柯式宣传单张 A5 **\$315/600张** 1 天交货 / 哑胶咭片 $50/100张 / 骑马钉书刊 2 天低至 5 折 / 纸袋 **\$2,049/300个** / 喜帖 $140/100张 / 月历 $1,350/50本。我们的 zh-hk 定价策略 = **e-print 的 85-95%** (深圳成本优势让利换单),en/ja 保持独立包邮价。

**我们现状的差距**: `pricing.ts calculateQuote()` 是**通用公式估算** (pages×0.5 + discountMap 100:0.7/500:0.6/1000:0.5),不是成本分解的真实价格表;`INDEPENDENT_PRICES` 只是展示用 min/max 区间。用户感知 = "报着玩的",不敢据此下单。这就是"报价功能用不上"的根因。

### C. 报价系统 3 阶段落地方案 (核心交付)

## 2. 反面思考:十个问题 (按致命度排序)

### P0-1. 支付断裂:客户想付钱也付不了 🔴

代码事实 (explore agent 审计):

* 结账页只有三种方式: **银行电汇 (DBS HK) / 微信二维码 / 支付宝二维码**。

* Airwallex 已废弃,注释写明"收单深圳主体无法开通";PayPal "审核中"未启用。

* 结账提交的 `/api/create-payment-session` **在仓库中不存在**。

* 无信用卡、无 PayPal、无任何美国/日本客户习以为常的支付方式。

**反面结论**: 对一个主打美国市场的跨境站,这意味着 en locale 的全部流量在支付环节**结构性归零**。\$50K/月 = 每天约 6-7 个订单 (AOV \$250 假设),靠"美国客户主动电汇到香港账户"达成这个数字的概率约等于零。这是全站第一优先级,高于一切 SEO 工作。

**衍生问题**: 收款主体 (深圳彩龙) 开不了 Airwallex — 这是主体资质问题,不是技术问题。需要决策:香港主体?Stripe Atlas?PayPal 企业?PingPong/连连?还是干脆放弃在线收款改 WhatsApp 询盘模式 (那商业模式和 \$50K 路径要重算)?

### P0-2. 双站分裂:搜索资产在"竞品"域名上闲置 🔴

实测 (2026-07-17):

* `www.z-printpro.com` — **200 OK,正常运行** (Tengine 服务器),老站还活着,还在收割全部 GSC 流量。

* `zprintpro.com` — 新站,Cloudflare Pages,正常运行。

* 两者之间**没有 301**,代码注释里称 z-printpro.com 为"竞品"。

**反面结论**: 现在是最差组合 — 老站有排名没转化 (静态站,无新漏斗),新站有漏斗没排名 (从零积累)。无论老站是不是自家资产,这都是必须立刻拍板的战略问题:

* 若老站是自家资产: 要么 301 全站迁移 (把 91 天 633 点击的资产和"智印港"品牌词带过来),要么明确双品牌分工 (老站=香港本地即日,新站=跨境三 locale),并在宪法里写清楚,而不是在代码里叫人家"竞品"的同时任其在线分流。

* 若老站真是竞品: 那 GSC 数据只是竞品情报,新站真实流量接近零,\$50K 目标的起点要再往下调一档。

**这是需要 user 回答的第一问题。**

### P0-3. en/ja 市场:内容机器在向未被验证的市场倾注产能 🔴

* 美国: 3,031 展示 / 5 点击。排名 6.2 却 CTR 0.16% — 这不是"再多写点博客"能解决的,这是**标题/摘要/定位对美国用户无效**的信号。

* 日本: 149 展示 — ja 内容在 Google 日本近乎隐形。

* 新站 7 月已产出 35 篇博客 (14 天),matrix 29 covered + 26 queue,按 180 天 730 篇的节奏全速推进。

**反面结论**: 180 天 730 篇的计划建立在"内容量 → 收录 → 排名 → 流量 → 收入"的链条上,但 GSC 数据显示链条的第一环 (en/ja 展示→点击) 已经断了。在验证"美国客户到底搜什么、点什么、买什么"之前,每多产 100 篇博客就多 100 篇的沉没成本。**先验证需求,再放产能。**

### P0-4. 线索端点断裂:表单提交静默失败 🔴

代码事实:

* 联系页 QuoteForm POST 到 `/api/send-quote-email` — **该路由在仓库中不存在**。

* 全站**没有任何事务邮件代码** (resend/sendgrid/nodemailer 均为零调用),只有 .env.example 里的占位 key。

* 邮件订阅弹窗走 Formspree 第三方,且只在 en 首页、延迟 5 秒才出现。

**反面结论**: 意味着每一个通过联系表单提交询盘的客户,都可能**静默流失** — 没有确认邮件、没有内部通知、没有 CRM 记录。对 B2B 印刷这种"询盘即生命线"的生意,这是每天在流血且无人知晓的伤口。(注: 需线上 POST 实测最终确认,但仓库内无此路由是事实。)

### P1-5. 假评论 Schema:在 Google 红线上跳舞 🟠

* 实测线上类目页输出 `"ratingValue":"4.9","reviewCount":128` — 硬编码假评分,全站无真实评价系统,页面上也看不到任何评论 UI。

* 老站 402 点击靠"评价摘要"富摘要 — 说明这个杠杆真实有效,但也说明一旦被 Google 判结构化数据作弊 (Review snippet spam policy),全站富摘要会被清零,CTR 直接掉一个档。

**反面结论**: 假评分是"收益确定、风险确定、爆雷时间不确定"的负债。正解不是删评分,而是**建真实的轻量评价收集** (订单后 WhatsApp/邮件邀评 → 入库 → 展示),把负债变资产。

### P1-6. 内容策略与收入模型错位 🟠

* 730 篇/180 天 = 每天 4 篇的产能要求,但当前 35 篇/14 天 (2.5 篇/天) 已在消耗大量 cron 算力与 build quota。

* 博客是**信息型内容**, targeting "选购指南";而 GSC 钱词 (紙袋訂製/包裝盒印刷/貼紙印刷) 是**交易型查询**,需要的是强类目页/PDP,不是博客。

* 老站数据已证明: 赢的页面是"产品×场景×即日×地名"的交易页,输的是泛类目页。

* 大规模模板化博客 (9 段结构 × 4 FAQ × 每日量产) 在 2026 年的 Google helpful-content 环境下,边际收益递减、被判定为规模化低价值内容的风险递增。

**反面结论**: 把 70% 的 SEO 火力从"新博客"转向"钱词着陆页攻坚" — 那 23 个季度展示 6,400 次、排名 25-57 的词,每一个都值得一个教科书级 PDP/类目页 + 内链支持,而不是再写一篇科普。

### c 🟠

* 宪法 §11: 名片是禁区,永不出现。

* 代码事实: products.ts 里**仍有 6 个 business-cards SKU**,14 个类目里包含 business-cards。

* 老站 GSC: 名片相关词 (名片印刷/印名片價格/印咭片 ≈ 254 展示) 被主动放弃。

**反面结论**: 不是说要解除禁令 (user 已拍板),而是数据层与宪法不一致本身就是运维风险 — sitemap、内链、schema 都可能把这 6 个 SKU 输出到线上,与"ZprintPro 不做名片"的品牌承诺打架。要么物理删除,要么明确隔离。战略上还要意识到: 主动放弃名片词 = 放弃香港印刷搜索的一大块高频流量入口,这个决定的成本要算清楚 (名片是香港印刷业获客的经典引流品,引流后交叉销售贴纸/宣传单张是行业惯例 — 禁区值得定期复议)。

### P1-8. 度量体系错位:verify 的是"部署",不是"生意" 🟠

* 7 步 verify 流水线验证的是: push 成功、sitemap 更新、curl 200、关键词出现、schema 注入 — **全部是"东西上线了"**。

* 没有任何一环验证: 页面被收录了吗?钱词排名动了吗?quote start 了几个?WhatsApp 点了几个?成交了吗?

* analytics.ts 里其实已埋了 18 个事件 (quote\_start/submit、whatsapp\_click 等),但没有任何 cron/报告在消费这些事件数据。

**反面结论**: 整个运维体系在优化"过程合规",不优化"结果"。需要一张从最上层 (收入) 到最下层 (收录) 的漏斗看板,每周用数字说话,而不是用"已上线 N 篇"说话。

### P2-9. 转化后端缺失:没有留存引擎 🟡

代码事实:

* 无账户体系 (supabase 有 user\_profiles 表但无登录 UI)。

* 购物车只存 localStorage,无服务端同步,无弃购挽回。

* 无事务邮件 (订单确认、报价单、催付、复购提醒全部没有)。

* 无 CRM — WhatsApp 询盘只往 supabase 表里 fire-and-forget 插一条记录。

**反面结论**: 印刷是复购生意 (宪法自己的 Tier A 逻辑: 餐饮/零售/电商月级复购),但站点把所有客户都当一次性流量。\$50K/月的稳态收入结构里,复购通常应占 40-60% — 没有留存引擎,等于每个月都要从零获客,获客成本永远降不下来。

### P2-10. 运维熵增:复杂度超过了业务阶段 🟡

* 7 月 10 日以来 89 个 commit — 与"1 push/天"的宪法明显背离,build quota 在燃烧。

* scripts/ 目录 207 个文件,大量一次性 fix-\* 脚本。

* 4 条 cron + guard cron + 监控 cron + 7 步 verify + matrix 调度 — 这套体系的维护成本,相对当前≈0 的在线收入,已经失衡。

**反面结论**: 运维体系是按"日均 4 篇、多市场、高产量"设计的,但业务还在"验证第一笔在线收入"的阶段。复杂度应该跟收入走,不应该跟规划走。

## 3. \$50K/月的数学 (Unit Economics 反推)

以 AOV 三档情景反推所需漏斗:

| 情景             | AOV   | 所需订单/月 | 所需订单/天 | 按 1.5% 访问→支付转化 | 所需访问/天  |
| -------------- | ----- | ------ | ------ | -------------- | ------- |
| 低客单 (香港本地零售)   | \$100 | 500    | 16.7   | <br />         | \~1,100 |
| 中客单 (跨境小批量)    | \$250 | 200    | 6.7    | <br />         | \~440   |
| 高客单 (B2B 包装定制) | \$600 | 83     | 2.8    | <br />         | \~185   |

**现状基线**: 老站 \~7 点击/天 + 新站自然流量≈0 + 在线支付不可用。

**三个推论**:

1. **纯 SEO 路径在 6-12 个月内到不了 \$50K/月。** 即使钱词全部做到首页,香港池子 (23 个词季度 6,400 展示) 也只能支撑每天 \~3-4 个高意向访问。必须靠"高 AOV × B2B × 复购"和付费渠道放大。
2. **AOV 是最有力的杠杆。** 订单数需求随 AOV 反比下降 — 跨境 B2B 包装定制 (AOV \$300-800) 是唯一能让 SEO 流量量级匹配 \$50K 目标的模型。这反过来支持 Tier A 行业方向 (跨境电商/美妆/餐饮包装),但落地页必须是交易页不是博客。
3. **付费流量必须尽早 pilot。** 以 \$1-2 CPC 买 200 访问/天 = \$200-400/天预算,在中客单情景下需要 ROAS ≥ 2.5 才能跑正 — 这只有在"在线支付可用 + 着陆页是交易页"的前提下才有资格测试。

## 4. 分维度专家判断

### 4.1 PM 判断:定位与 ICP

* **最清晰的 ICP**: 跨境电商/独立站卖家 (Shopify/Amazon) 的包装定制 — 贴纸/包装盒/纸袋,月级复购,AOV \$300-800,决策链短,在线支付习惯成熟。这与 Tier A 矩阵方向一致,但落地形态要从"科普博客"改为"行业解决方案页 + 即时报价 + 在线下单"。

* **香港本地市场**: 真实、已验证、但天花板低 (本地零售 AOV 低)。正确定位是**现金流和口碑的基本盘**,不是 \$50K 的主引擎。老站已经证明"即日+地名+产品"的页面模型有效 — 这个模型应该在新站 zh-hk locale 复刻 (rush-printing-delivery 服务页就是这个思路,值得扩成矩阵)。

* **日本市场**: 149 展示/91 天说明近乎零起点,且日本 B2B 印刷跨境采购的信任门槛最高。建议降为"维持合规存在,不投入产能",把 ja 算力让给 en。

### 4.2 UX 判断:漏斗断点图

```
访问 → PDP/类目页 → QuoteCalculator (✅ 客户端即时报价,做得好)
     → 加入购物车 (⚠️ localStorage,无同步)
     → 结账 (🔴 无在线支付,只有电汇/QR)
     → 支付 (🔴 对美国/日本客户结构性不可行)
     → 确认/留存 (🔴 无事务邮件/无账户/无挽回)
旁路: 联系表单 (🔴 端点缺失,可能静默失败)
      WhatsApp (✅ 可用,是当前唯一真实转化通道)
```

**优先修**: 支付 > 表单端点 > 订单确认邮件 > 评价系统。

### 4.3 SEO 判断

1. **资产迁移决策优先于一切内容工作** (见 P0-2)。
2. **火力再分配**: 70% 投入 23 个钱词的着陆页攻坚 (PDP 教科书化 + 内链 + 富摘要真实化),30% 维持博客节奏。每个钱词指定唯一权威着陆页,避免博客与类目页互相蚕食 (老站 paper-bag 类目页 6,231 展示 6 点击就是蚕食/薄页的下场)。
3. **美国 CTR 0.16% 专项**: 排名 6.2 无人点 = 标题/摘要不匹配美国搜索意图。抽查 en 标题 "Custom Paper Bags Free Shipping · 100 MOQ FSC Kraft Eco" — 方向对,但要逐个对照 SERP 竞品 (Packhelp/Packlane/UPrinting 的标题公式: 价格锚点 + 交期 + 免费打样) 重写,并用 GSC URL filter /en/ 单独监控。
4. **收录监控**: 7 月已发 35 篇,宪法规定"7 天无收录升级" — 需要确认这个监控真的在跑 (GSC API 索引状态),否则 730 篇计划可能在向一个不收的池子里倒水。
5. **假评分 schema 替换为真实评价** (见 P1-5),保住富摘要杠杆。

### 4.4 营销判断

* **当前唯一真实转化通道是 WhatsApp** — 那就把它当正式通道运营: 自动回复话术、报价 SLA (30 秒 AI 报价的品牌承诺要在 WhatsApp 端兑现)、询盘标签、每周询盘→成交转化统计。

* **付费 pilot (修完支付后立刻)**: Google Ads 只投两组 — (a) 香港钱词组 (紙袋訂製/包裝盒印刷/貼紙印刷,着陆页=对应类目页),日预算 \$30-50;(b) en 跨境包装词组 (custom packaging boxes / custom stickers bulk,着陆页=解决方案页),日预算 \$50-100。目标不是赚钱,是 30 天内测出真实 CAC 和转化率,校准 \$50K 路径。

* **B2B 外联**: trade-program 页已存在但没有流量入口。跨境电商包装客户应该用"免费打样 + 首单折扣"的 outbound (LinkedIn/邮件/Shopify 社群) 直接获取,这是高 AOV 订单最快的来源,不依赖 SEO。

* **品牌词问题**: "智印港"25 展示 16 点击排名第一 — 需要 user 拍板这个词的资产归属 (见 P0-2)。如果老站是自家资产,品牌词迁移/合并的说明书要补上。

### 4.5 运维判断

* **把 cron 从"生产导向"改为"结果导向"**: daily-content-evolve 降频 (每周 2-3 篇高质量,替换每天 2-3 篇),释放的算力投给钱词着陆页和 en CTR 重写。

* **加一条 revenue-analytics 周报**: 消费已有的 18 个 GA4 事件 + Supabase quotes/whatsapp\_inquiries/orders 表,每周一输出"流量→报价→询盘→订单→收入"漏斗,替代现在的"上线 N 篇"汇报口径。

* **build quota 整顿**: 89 commit/7 天 → 回到攒批节奏,否则 500 次/月的配额会在内容放量期先爆掉。

* **scripts/ 207 个文件**: 冻结新增一次性脚本,通用逻辑收进 5-6 个维护中的工具,其余归档到 scripts/archive/。
