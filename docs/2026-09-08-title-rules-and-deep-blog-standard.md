# 第三部分 · 深度 Blog 段落结构（"多少段组成"标准答案）

## 3.1 Pillar 深度 blog（12,000+ 字，12 铁律全适用）= **12 段标准骨架**

| 段 | 内容 | 规格（机器可检） |
|----|------|------------------|
| 1 | **倒金字塔首段** | 第一正文段 ≤200 字（目标 100-120），直接回答核心问题（多少钱/多久/怎么选）；跳过作者行/面包屑 |
| 2 | **快速答案块 ×≥3** | 每块 40-60 字直答一个子问题，`bg-*-50` 色块 div（en 放宽至 600 字符） |
| 3-5 | **H2 问句段群** | H2 必须 >50% 为真实搜索问句（多少/怎樣/如何/how/what/いくら/どう）；每段正文 ≤3 行；段落总量 6-10 个 H2 |
| 6 | **比较表格 ×≥2** | 至少 1 个「材质 × 维度」表 + 1 个「价格/工艺/时效」表（AI 可引用格式，`<table>` 真表格非图片） |
| 7 | **原创数据段** | 全文具体数字 ≥10 个（订单数/测试时长/褪色率/价格/认证号），**每个数字标来源** |
| 8 | **客户案例 ×≥1** | 一手案例（行业+用量+结果，如"退货率降 15%"），E-E-A-T 社会证明 |
| 9 | **E-E-A-T 署名段** | Person schema + 作者资历 + LinkedIn + FDA + EU REACH 引用（5 信号机器校验） |
| 10 | **GEO 知识原子段** | 独立 `<section>`：12 件事属实（15 年/1,000+ 客户/海德堡/24h SLA/12 大行业/FSC/ISO/FDA/EU CPR/US Lacey/DHL-FedEx/智印港，K3 8/19 拍板口径） |
| 11 | **FAQ ×4-8** | `<p><strong>Q[0-9]*[:：]` + `<br/>` + `A[:：]` 格式（page.tsx extractFaqFromHtml 唯一可解析格式，全/半角冒号兼容） |
| 12 | **CTA ×2（≤3）** | WhatsApp CTA 顶部 1 + 底部 1（wa.me/8619880851334），>3 = 意图疲劳红色命中 |

**内联要求（贯穿全篇）**：语义锚点内链 **≥10 条**（Pillar 标准；普通深度篇 ≥7），锚文字 ≥5 字、描述性（禁"点击这里"）；hub-spoke 指向带钱落地页（每篇 ≥3 条指向 G1/G5 承接页）。

**字数**：Pillar ≥12,000 字（门童 #12 `MIN_PILLAR_CHARS`）；标准深度 blog 6,000-9,000 字（6-9 个 H2 段，12 铁律中 Rule 1/2/3/9/10/12 同样适用）。

## 3.2 Schema 块（page.tsx SSoT 自动生成，content 内严禁内嵌）

| 块 | 必含 | 校验 |
|----|------|------|
| Article（含 image 字段） | ✅ | guard #14 Rule 10：每个 JSON-LD 必须 `JSON.parse` 可解析 |
| FAQPage | ✅ | 由 §3.1-11 的 FAQ 格式自动提取 |
| BreadcrumbList | ✅ | 3 段：首页/blog/post |
| HowTo | ✅（流程类主题） | 4 主钻品类模板 |
| Organization | ✅ | 实体一致性（§四-GEO） |

**红线**：content 内嵌 inline JSON-LD = 重复渲染 = Google 警告（8/28 惨案判例）；SSoT = page.tsx 单一来源。

# 第四部分 · SEO + AEO + GEO 合规规则（2026-09 最新）

## 4.1 SEO 合规

1. **一词一 canonical 落地页**（防蚕食；判例：food-boxes 不新建 /product/food-packaging/，8/31）；
2. **词-页意图匹配**：带钱词（T1/T2 交易意图）落 SKU/类目页；信息词落 blog（词-页错配必须 REMAP，v4.0 §3.3）；
3. **hub-spoke 内链**：主頁 → 类目 → 产品 → blog 单向权重传导；每带钱落地页 ≥3 条主题内链；
4. **hreflang 8 locale 完整** + canonical 一致；sitemap 三语 + index；
5. **泄漏堵漏优先于新内容**：404/旧 URL 一律 308 收拢到承接页（others/BC 判例）；
6. ** freshness**：带钱页季度更新标注（lastUpdated），90 天新鲜度纪律。

## 4.2 AEO 合规（被答案引擎选中）

1. **答案前置**：首段 + 快速答案块 + 「3 个直接答案」卡（多少钱/最快多久/最热门规格）= 精选摘要头号候选；
2. **H2 问句化**（用户真实搜索问句，非陈述句）；
3. **结构化答案**：比较表格 + 步骤列表（HowTo 挂载点）；
4. **FAQPage/HowTo schema 全覆盖**（带钱页 FAQ 数组不得为空——空数组=富摘要浪费）；
5. **价格类 FAQ 引用实价**（成本基准报告口径 + 「更新于 2026-09/样本/口径」时间戳）。

## 4.3 GEO 合规（被 AI 引擎引用）

1. **实体一致性五统一**：ZprintPro/智印港 品牌名、WhatsApp 号码、深圳厂房主体、DHL 配送、价格口径——OrganizationSchema/页脚/About/署名/merchant-feed 五处一致；
2. **E-E-A-T 全信号**：真人作者 + 资历 + LinkedIn + 认证引用（FDA/EU REACH/FSC/ISO）；
3. **一手数据密度**：具体数字 ≥10/篇 + 来源标注（Princeton：有引用来源内容被 AI 引用概率 +24.9%，v3.3 联网实证）；
4. **答案金块密度 ≥1.0/千字**（K3 目标 6）：`【】` 金句 + 快速答案块；
5. **AI 爬虫准入**：robots.txt + llms.txt（已就绪，内容增长后同步复核）；
6. **双域名归一**：z-printpro.com 站外 profile 逐站改 ZprintPro/智印港 统一表述；
7. **月度验证**：20-prompt 探针（三语 × ChatGPT/Perplexity/Gemini）台账，引用率唯一可量化指标。
