## §1 每日固定动作（D1-D30 每天必做，不重复列入逐日表）

1. **早间只读监测**（5 分钟）：GSC 24h 窗看食品包裝印刷/紙袋印刷/small batch 簇排名与点击——**只记录，不动词**；
2. **push 纪律**：当日改动攒批，距上次 push ≥30 分钟硬下限 + 达攒批阈值（≥3 非 docs / ≥1 src 修复 / ≥1 战略交付物）才推；不足则留次日；
3. **三闸门**：push 前 encoding + tsc + build 全过；push 后 verify-deploy + 关键 URL curl 200；
4. **EOD 报告**：含数据来源行 + 完成状态分级（✅已完成=有证据 / ⏳已排期 / 🔴撞墙），不写"笼统批准=已完成"（§0.24）；
5. **cron 共存**：daily 10:15 / weekly 11:00 等既有 cron 自动 push 与本计划攒批 push 共享 30 分钟间隔池，撞窗时本计划让步给 cron。
