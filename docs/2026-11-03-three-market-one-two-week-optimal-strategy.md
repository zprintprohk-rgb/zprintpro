# ZprintPro 三站点未来 1–2 周最优 SEO／AEO／GEO 战略

> 角色：ZprintPro 首席搜索数据分析与战略参谋  
> 日期：2026-11-03  
> 范围：zh-hk／en／ja；承接 10-26 双引擎、包装盒、七词簇战略，10-28 数据驱动战略，10-30 完成度审计及 10-31 带钱词战略。  
> 性质：基于已落盘 GSC、执行结果、GEO 探针与竞品采购信息架构的下一阶段方案；不是流量、询盘或收入预测。

## 〇、总决策

**未来 1–2 周停止“看到深位词就新增长文”的惯性，顺序改为：先修首页 CTR 候选，再测量交易页／Blog 承接，最后才决定是否扩内容。**

理由不是曝光不足，而是曝光到点击的转化链条仍有明确缺口：

- 最新 28 天窗口 `2026-10-04..2026-10-31`：504 点击、22,114 展示、CTR 2.28%、平均位置 14.03。
- 最新 24 小时：23 点击、977 展示；相对最近 28 天日均 789.8 展示的动态恢复系数为 **123.7%**。这只是**全国家曝光指标恢复**，不能推出排名、处罚、询盘、订单或收入恢复。
- 23 个重点商业词只有 6 个进入首页；其中 5 个合计 196 展示、0 点击。最大的单项缺口是 `食品包裝印刷`：118 展示、0 点击、位置 8.42。
- 海报、贴纸、书刊的承接仍有分散信号，但分散份额不是自动 301、canonical 或删页的证据。
- GEO S1 已完成 7 簇双跑，引用 URL 尚未完整采集；当前不能把 AI 提及变化写成增长，也不能因 ja 缺席直接发文。

因此，下一阶段的最小增长单元不是“一篇文章”，而是：

> **冻结基线 → 明确一个证据缺口 → 审批一个变量 → 生产部署 → 在线核验 → D1／D2 健康检查 → 7／14／28 天复测 → 决定 FIX／MEASURE／SCALE／STOP。**

### 1.2 仍存在的测量限制

1. **xlsx 新鲜，API 平面仍旧**：最新 xlsx 数据日为 10 月 31 日；API 最新数据日仍为 10 月 30 日，11 月 3 日未完成 end1103 拉取。
2. **窗口高度重叠**：新旧 28 天窗口重叠 24 天，窗口移动只能作为观察，不能当作独立实验复测。
3. **维度不可硬连接**：query、page、country 独立汇总不能拼成“某词在某国某页”的精确总量；query×page×country 专门导出才可支持承接判断。
4. **GSC 不是商业结果**：没有 GA4／008／订单落地页覆盖，不做询盘转化率或 ROI 结论。
5. **不自动抓 Google SERP**：真实 SERP feature 与 snippet 由人工／获批浏览器核验；日常复测以 GSC 为主，遵守 Google 自动查询与垃圾政策边界。

## 二、三市场优先级

### 2.1 zh-hk：先拿首页点击，再解决交易承接

#### Z1｜食品包装：首页 CTR 诊断，优先级 P1

- **冻结基线**：`食品包裝印刷` 118 展示／0 点击／pos 8.42，28 天全国家 xlsx。
- **问题类型**：FIX 候选，不是新长文候选。
- **先测量**：记录实际排名页、标题链接、摘要、SERP feature、竞品展示形态及设备差异；确认是否由正文摘要、价格／交期信息不清或搜索结果形态导致零点击。
- **允许动作**：审批后只改一个 snippet 相关变量；不得同批改 title、正文、价格和结构化数据。
- **商业门禁**：MOQ、价格、打样、食品接触、认证和交期只使用已批准真值；没有真值就不写数字。
- **复测**：上线后 D1／D2 检查展示与索引健康，7／14／28 天比较同口径 CTR、点击和展示；未上线不得进入学习候选。

Google 官方规则对本阶段的约束：

1. 标题链接应描述页面内容，避免重复、样板化和关键词堆砌；先核验 Google 实际选择，再决定是否修改。
2. 摘要主要来自页面正文；meta description 不是保证显示的摘要，因此不能只改 description 就宣称完成 CTR 修复。
3. Google 没有偏好字数；12 段骨架是采购完整性工具，不是排名快捷键。
4. 不批量生产低价值、近重复或仅为搜索流量存在的页面；不自动抓取 Google 结果作为排名监控。

## 五、统一准入、复测与退出规则

### FIX 准入

- 有明确页面／查询基线和可解释缺陷。
- 首页零点击项先完成 SERP feature 与真实 snippet 审核。
- 有审批人、一个变量、生产部署计划、在线核验和复测日期。

### MEASURE 准入

- 深位词、承接分散、索引异常、AI 缺席和商业真值未决项。
- 只补齐 index、intent、query×page×country、线上页面与竞品 IA 证据。
- 测量完成可输出 FIX 提案，但不能自动变成内容生产。

### SCALE 准入

必须同时存在：

`baseline + change + production_deploy + online_verify + retest + scale_evidence`

且改善在可比较窗口复现。缺一项就保持 FIX／MEASURE，不进入共享规则，不复制到三站点。

### 退出与失败处理

- **复测完成**：记录胜负或证据不足，均有退出权。
- **WAITING_K3**：停止商业变更，保留测量。
- **BLOCKED_INFRA**：记录 owner、retry_at、cooldown 和恢复条件；同因失败不无间隔重试。
- **NO_OP**：当没有真实信息增益时，这是合格结果，不是“任务没做”。
- **STOP**：有明确停止证据时停止扩张；不自动删页、noindex、301 或 canonical。

## 六、需要继续保留的人审与基础设施事项

4. 11 月 1 日月度自然任务缺失和 API 拉取缺口不是内容问题，不能用更多长文掩盖。
5. 本战略与 prompt 更新不等于自然定时调度已经恢复；须以自然触发后的 run record、wrapper 日志和当日产物验收。
