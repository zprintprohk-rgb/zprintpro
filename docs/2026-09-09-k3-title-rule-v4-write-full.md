## 一、标题规则 v4 · 写满原则（K3 9/9 06:18 拍板，替代 v3/v3.1 区间表）

### 1.1 口径（不变）
半角当量：全角 CJK 字符 ×2，半角字符 ×1。K3「<55 个字符」按既有半角当量口径执行（= zh-hk 25-27 全角 / en 50-54 raw chars / ja 25-27 全角），与 Google SERP ~580px 标题显示宽度对应。

### 1.2 新区间表（替代 v3.1 三区间）

| 区间 | 半角当量 | 状态 | 处置 |
|------|----------|------|------|
| **写满区（目标）** | **50-54** | ✅ 新标准 | 主词前置 + 长尾词/工艺修饰/数字钩子填充至**逼近 54**，品牌末尾一次 |
| 满格线 | ≥55 | ⛔ 禁加 | 防 Google 76% 重写，禁加任何元素（不变） |
| 遗留容忍区 | 55-60 | ⚠️ 只读 | 在窗批次不动；9/13 后新改一律收到 ≤54 |
| 超限区 | 60-80 | 🔴 待修剪 | 9/13 合批时修剪回 50-54 |
| 不足线 | <50 | 🔧 按序补 | ① GSC 实证同簇长尾（可多个）② 数字钩子 ③ 工艺修饰 ④ 品牌兜底 |

### 1.3 长尾词填充新规（终裁 §1.5 待确认项）
- 写满原则下，**独立长尾词允许 1-2 个**（v3「只上 1 个」废止）；每个必须过 3 筛选（① GSC 有展示实证 ② T1/T2 采购意图 ③ 与主词同簇）；
- 第 2 个长尾**仅在写不满 50 时启用**；写满 50-54 即止，不为堆砌而堆砌；
- 业务洞察词（FDA 級/月饼/茶葉/烘焙等 GSC 0 展示词）仍禁入 title，只进 meta/正文/keywords（不变）。

### 1.4 不变项
四元素结构（主词→修饰→数字钩子→品牌）/ 跨语言污染零容忍 / 冻结 2-4 周 / 改动前后必跑当量脚本存档 / en·ja 禁繁中。

### 1.5 五视角裁决摘要
| 视角 | 裁决 |
|------|------|
| CEO | 采纳。SERP 像素是免费资产，写满=最大化关键词覆盖，不破 55=不触重写 |
| PM | 9/13 验证窗判定后首批合批按 v4 执行；窗内纪律不动 |
| UI/UX+CRO | 写满区标题信息密度升，但品牌末尾+数字钩子前置保持可读性 |
| 运营/转化 | 数字钩子（MOQ/价格/交期）是 CTR 弹药，写满时优先保数字钩子 |
| 数据 | 以 9/3 canonical 为基线；9/13 判定后 v4 批次进新验证窗（改后 7-10 天只读） |
