## 一、修复判定 (K3 拍板"达到现在对 blog 的标准 + 排版格式也要规范")

| 维度 | 判定 | 修复方法 |
|---|---|---|
| **缺 en/ja native** | 旧 blog 缺 3 locale 或 en/ja 直译 zh-hk | **重写 en/ja** (native 英文 + 日文, 不直译) |
| **缺 9 段** | 旧 blog 5-7 段 | **重构 9 段** (引子 60-80 + 主段 × 7 100-150 + CTA 30-50) |
| **缺 4 FAQ** | 旧 blog 0-3 FAQ | **加 4 FAQ** (H3 + p 简答 30-50 字) |
| **缺 5 内链** | 旧 blog 0-4 内链 | **加 5 内链** (1-2 类目 + 1 服务 + 1 blog + 1-2 相关) |
| **缺 JSON-LD BlogPosting** | 旧 blog 0-1 schema | **加 JSON-LD BlogPosting** (含 author/datePublished/articleBody) |
| **7 Anti-AI-Slop 不达标** | 旧 blog AI 套话 (在當今數字化時代 / 提供優質服務) | **重写文案** (数字+品牌+来源) |
| **排版格式不规范** | 旧 blog H1/H2/H3/ul 混用 | **规范化** (H1 文章标题 / H2 段 / H3 FAQ / ul/li 列表) |
| **互链思考不足** | 旧 blog 内链弱 | **加 5 内链** (互链密度优化, 跟当前热门类目 + 服务页 + 相关 blog 互链) |
| **缺 zh-hk 800-1000 字** | 旧 blog 500-700 字 | **扩写** (加 1-2 段到 800-1000) |
| **缺品牌一致性** | 旧 blog 缺智印港 / ZprintPro 双品牌 | **加品牌** (header/footer 智印港双品牌 + ISO 9001 + FSC) |
| **缺 Last Updated** | 旧 blog 缺日期 | **加 Last Updated 2026-XX-XX** (跟 K3 §13.4 模板) |
| **缺 7 Anti-AI-Slop 数据来源** | 旧 blog 数字 + 来源弱 | **加数据来源** (GSC 8/18 / 008-baseline-v1.md / autoclaw) |
