# SKU 标题规则 v5 · 长尾补源增强版（K3 拍板 · 2026-09-23）

> **性质**：标题规则 v4「写满原则」的增补修订，非替代。v4 全部不变项继续有效；本版只解决一个缺口——**长尾词「无 GSC 实证时怎么办」**，并固化 SKU 级（非博客级）的全部操作细则。
> **拍板来源**：K3 2026-09-23 指令（两次）——①「主词 + 1-2 个 GSC 实证同簇长尾 + 工艺词/尺寸 + 数字钩子 + 品牌末尾一次；当量 50–57，≥58 硬拦；无 GSC 实证长尾 → 联网搜索补词」；②「关键词库来源新增 `F:\全球印刷资讯\DELIVERY`（联网搜索得到的全球需求用户词，含带钱词与流量大词，最高优先级）；无 GSC 数据时，须结合用户搜索习惯深度推导最优标题」。
> **取代关系**：本文件 §二 取代 v4 §1.3 长尾来源条款；其余条款与 v4 并行有效。

## 一、结构（五段式，顺序固定）

```
[主词] + [长尾词 1–2 个] + [工艺词/尺寸] + [数字钩子] + [品牌末尾一次]
```

| 段位 | 内容 | 规则 |
|------|------|------|
| ① 主词 | 品类核心采购词 | 必须是该 SKU 落地页 GSC 有展示的主词或其规范变体；前置，不可让位 |
| ② 长尾 | 1–2 个，见 §二来源阶梯 | 每个必须过 §二.3 三筛选；第 2 个仅当加完①③④后当量仍 <50 才启用 |
| ③ 工艺/尺寸 | 材质、工艺、规格词 | 只写 SKU 真实具备的（products.ts 条目可证）；禁止跨品类借用 |
| ④ 数字钩子 | MOQ / 价格 / 交期 三选一，最多两个 | 一律引 products.ts 现行条目或 K3 拍板 FAQ，**禁编造**；优先级：差异化 MOQ > 价格 > 交期 |
| ⑤ 品牌 | 「智印港」（zh-hk）/「ZprintPro」（en/ja） | 全标题只出现一次；与④之间用「｜」或空格分隔 |

**当量带**：半角当量 50–57。全角 CJK ×2，半角 ×1。`<50` 按 ②→③→④ 顺序补；`≥58` 硬拦（band(58)=TRIM，title-equiv.js 执行）。实测目标逼近 54–57（SERP 像素吃满、远离截断线）。

## 二、长尾词来源阶梯（本版核心增量）

### 2.1 四级来源，按序穷尽

```
L0 · 全球需求词库 F:\全球印刷资讯\DELIVERY（K3 9/23 新增 · 最高优先）
   └─ 性质：联网搜索得到的全球需求用户真实检索词，已含带钱词与流量大词
   └─ 用法：先查词库。词库内与主词同簇的带钱词/流量大词 → 直接入选长尾位，
      优先级高于一切其他来源；词库命中即不再往下走 L1/L2
   └─ 判定：同簇（同品类同买家）+ 带钱意图（询价/订製/MOQ/批发/小ロット）
      或流量大词（品类核心需求词）；**带钱词 > 流量大词 > 其他**
   └─ 记录义务：「长尾：xxx｜来源：DELIVERY 词库｜档位：带钱/流量大｜日期」

L1 · GSC 实证同簇长尾（词库未命中时）
   └─ 来源：GSC 导出 query 明细（canonical）+ 带钱词地图
   └─ 判定：该词在 GSC 有展示记录，且与主词同簇（同一品类、同一意图层）

L2 · 联网搜索实证长尾（词库未命中且无 GSC 数据时启用）
   └─ 方法：web 搜索「主词 + 高意图修饰」组合，取真实 SERP/平台中
      买家实际使用的长尾变体（竞争对手 title、Alibaba/行业目录
      的 buyer search 词、Google 相关搜索）——**深度思考用户搜索习惯**：
      这个品类的买家会用什么词找货？数量词怎么写？要不要价格？
      本地买家与跨境买家的措辞差异是什么？穷尽 100% 能力推导后再定词
   └─ 记录义务：补的词必须写入报告「长尾来源行」，格式：
      「长尾：xxx｜来源：联网搜索｜证据：<URL 或截图锚点>｜日期：YYYY-MM-DD」

L3 · 无来源不用（禁区）
   └─ L0–L2 都拿不到 → 该位留空，用工艺词/数字钩子补满，宁缺毋编。
      编造长尾 = 数据诚信违规（§0.23 级），当次交付作废。
```

> **无 GSC 数据场景总原则**：SKU 无 GSC 数据 ≠ 可以拍脑袋。顺序固定为——**先查 DELIVERY 词库（带钱词/流量大词优先）→ 再联网搜索补词（按买家搜索习惯深度推导）→ 仍无则留空补工艺与数字**。三条路穷尽后仍 <50 当量，才允许用工艺修饰凑满，且报告须写明推导全过程。

### 2.2 L2 联网补词 · 检索式模板（直接可用）

| 语言 | 检索式 |
|------|--------|
| zh-hk | `<主词> 訂製`、`少量<主词>`、`<主词> 起印`、`邊度 印 <主词>`、`<品类>印刷 價錢` |
| en | `small batch <keyword>`、`custom <keyword> low MOQ`、`cheap <keyword> printing china`、`buy <keyword> wholesale` |
| ja | `<品類> 印刷 小ロット`、`オリジナル <品類> 作成`、`<品類> 印刷 即日`、`<品類> 業務用` |

**真实买家长尾的形态证据**（2026-09-23 联网实测，作选词参照，非直接入题）：
- 低 MOQ 词族是 B2B 搜索的结构性增长方向——买家搜索 increasingly 带 "small batch / low MOQ / 少量 / 小ロット / 1件起印" 修饰，MOQ 透明度本身是排名与转化弹药<REF>cite✦tools://web_search:1#0:~:text=Low MOQ Visibility...self-select by MOQ</REF>；
- 香港买家真实用法：「1件起印」「少量印刷」「傳單最少10張」式数量词 + 品类词，竞品 TIPTOP/駿璟/Design Easy 的 MOQ 表述即买家词汇库<REF>cite✦tools://web_search:1#5:~:text=大部分產品最少1件起印...貼紙最少1張</REF>；
- 英语买家高频意图修饰：custom / low MOQ / for small business / wholesale / china<REF>cite✦tools://web_search:1#0:~:text=custom sticker label for small business...geographic modifiers</REF>。

### 2.3 三筛选（L1、L2 通用，逐词必过）

1. **意图筛选**：T1/T2 采购或询价意图（含「订製/小批量/价钱/起印/MOQ/wholesale/小ロット/激安」类修饰）；how/what/guide 类 AEO 词**不进 title**，归 meta/正文；
2. **同簇筛选**：与主词同品类、同买家；跨品类词 = P0（防蚕食）；
3. **不重复筛选**：不得与本 SKU 已用长尾、同簇其他 SKU title 中的长尾重复（跑重复扫描，幂等三问第 2 问）。

**翻译层铁律**：长尾从 zh-hk 借到 en/ja 时必须本地化为真实检索词（如 zh「小批量貼紙」→ en「small batch stickers」→ ja「ステッカー印刷 小ロット」），禁止逐字翻译；ja 标题**禁用「份」**（量词用「枚/個/本/セット」，与站内口径一致）。

## 三、各语言标定（写满带换算）

| 语言 | 全角带 | 示例基准 | 备注 |
|------|--------|----------|------|
| zh-hk | 25–27 全角 | 25 全角≈50 当量 | 数字钩子用阿拉伯数字（「10張起印」比「十張起印」省 1 全角） |
| en | 50–57 raw | 直接计 | 长尾含空格按 1 当量/字符 |
| ja | 25–27 全角 | 同 zh-hk | 片假名外来词按全角计；MOQ 用「～枚」格式 |

**填满顺序**（当量 <50 时）：② 补第 2 个长尾 → ③ 补工艺/尺寸 → ④ 补第 2 个数字钩子 → ⑤ 已无法再动则品牌前加地域工艺修饰（仅限真实产能表述）。任何一步让当量 ≥58 → 回退该步。

## 四、禁令清单（写标题前逐条自检）

- ⛔ 空洞修饰词：香港印刷 / 印刷專家 / 品質保證 / 專業 / high quality / best / 激安（无价格证据时）——零信息密度，挤占当量；
- ⛔ 跨品类词：主词是貼紙就不得塞紙袋/包裝词（蚕食红线）；
- ⛔ 重复品牌：「智印港 ZprintPro」双品牌并列 = 违规，只留一个；
- ⛔ 无来源数字：MOQ/价格/交期无 products.ts 或拍板 FAQ 出处 = 数据诚信违规；
- ⛔ GSC 0 展示词进 title（v4 铁律，L2 补的词不受此限但须过 §2.3）；
- ⛔ 跨语言污染：en/ja 禁繁中字符（「禮盒訂製」判例）；ja 禁「份」；
- ⛔ ≥58 当量（硬拦）与 SERP 截断（逼近 58 视为临界，优先砍空洞修饰而非砍数字钩子）。

## 五、验收与留档（缺一不交付）

1. **当量体检 3 行**：改前 / 改后 / 区间判定（title-equiv.js，TITLE_MIN=50 / TITLE_MAX=57）；
2. **长尾来源行**：每个长尾标注 L0（DELIVERY 词库+带钱/流量大档位）/ L1（GSC 档名+词）/ L2（URL+日期）；L0 与 L1 同时命中同一词时，来源行标「L0+L1」；
3. **数字来源行**：MOQ/价格/交期 ← products.ts 条目号或拍板 commit；
4. **重复扫描**：与同簇 SKU、同品类 title 无长尾重复；
5. **线上断言**：push 后 curl 该页 title 与 meta，确认线上生效（绕缓存 `?_cb=`）；
6. **改动入窗**：title 改动进 7–10 天只读验证窗，tracker 登记，窗满出 ΔCTR 报告；
7. **幂等三问**：开工先查该 SKU 是否已在窗内冻结名单 / 是否已达标登记（防重复建设）。
