## 一、招标承诺口径（K3 拍板，已落地为页面 + 门童 #18）

### 1.1 K3 口径原文（关键风控原则）

| # | 原则 | 要求 |
|---|------|------|
| 1 | **禁止确定性词汇** | ❌ 禁用「保证」「承诺」「确保」「已具备」「已完成」<br>✅ 替换为「拟」「计划」「预计」「以…为准」「待确认」 |
| 2 | **绑定生效条件** | 所有骨架内容必附前提，例：以最终签订的合同条款为准 / 以甲方书面确认的技术规格书为前提 / 以内部立项审批通过为生效条件 |
| 3 | **区分事实 vs 意向** | **认证 = 事实**：有就是有，没有就是没有；未获证绝不暗示已获证，只能写「符合标准」或「认证进行中」<br>**产能/交期 = 意向**：可给区间但必标「预估」 |
| 4 | **系统字段适配** | 强制数值字段填 0 或 9999，备注栏写「[待核定] 具体数值以审批后版本为准」；支持附件则上传《承诺事项待确认清单》PDF |
| 5 | **骨架→血肉转化节点** | **触发**: 收到中标通知书 / 签订框架协议 / 内部 OA 审批通过<br>**动作**: 替换占位符为确切数字与证书编号 → 删除所有「待确认」「以…为准」限定词 → 保留更新记录（截图/版本日志）以备审计<br>**复核**: 更新后须经法务/合规二次审核，确保与投标文件、合同条款完全一致 |
