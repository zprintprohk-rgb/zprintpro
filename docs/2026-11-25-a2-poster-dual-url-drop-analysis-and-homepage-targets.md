## 五、结构发现（页面侧，本地真值核对）

1. **双 URL 零互链**: blog 全文 0 条链到 `/zh-hk/product/a2-posters/`（只链 category/posters/ + 12 篇其它内容）；PDP 侧亦无回链 blog。hub-spoke 在「海報簇」内是断的——blog 有「頁面分工」声明（指南 vs 类目页交易），但 A2 规格级需求没有 spoke→PDP 通路。
2. **主承接归属未定案**: 海報印刷双 URL 均有展示（PDP 3mo 292 imp@34.5 / blog 3mo 427 imp，28d blog 114 = 全站 62%）。嫌疑 = Google 在两 URL 间摇摆；**处置前置条件 = K3 导出 query×page（GSC 效果→导出→「网页」+「查询」双维度）**；定案前不动 301/canonical/砍页（11-23 诊断铁律）。预判（供拍板参考）：海報印刷主承接 = blog，PDP 主攻 a2 簇——分工天然成立，互耗可解。
3. **SERP 旧价标题**: 图4 显示 blog SERP 标题「香港海報印刷 **HK$9 起**：…」——src 层已无 HK$9（blog 正文与 PDP 均为 HK$16 起/10 張起印，K3 9/19 裁决真值）→ 这是 **Google 缓存的 10-30 改价前旧标题改写**，属 re-crawl 刷新问题，非 src 真值错误，不需要（也不应）动 title。
4. **PDP 客戶評價 0 條**（图7/8）: 转化信任缺口 + Product schema 无 aggregateRating 可填充；**解法 = 收集真实首评（K3/客服真人动作），禁编造（SOP-10 第 3/4 款）**。
5. 价格真值已统一（A2 HK$16 起 / 10 張起印 / A1 HK$45 噴繪基材），blog 与 PDP 一致——10-28 文档 §7.1 关心的价格口径分裂在 src 层已闭合，外部层（GMC/SERP 缓存）另计。
