# ZprintPro 数据驱动下一阶段 SEO / AEO / GEO 战略

> 周期：2026-10-28 至 2026-11-27。适用范围：zh-hk / en / ja。
> 上游：三份 2026-10-26 战略与 10 月 26–28 执行审计。
> 核心转变：从“生产内容并报告完成”转为“每个任务都有证据、最小改动、线上验收、转化归因、复测与停止条件”。

## 1. 北极星与指标层级

**北极星：各语种非品牌采购词页带来的有效询盘，以及这些询盘的可追踪收入质量。**

| 层级 | 指标 | 不允许的误用 |
|---|---|---|
| 业务结果 | 有效询盘数、询盘有效率、订单数/收入（可追踪时）、landing page 与语种 | 没有 GA4/008/订单对齐前不得编转化率 |
| 搜索表现 | 同口径非品牌 clicks、query-page CTR、平均位置、索引覆盖 | GSC 展示不是市场总量；不同聚合范围不得相加 |
| AEO 可提取性 | 采购问题有直接答案、规格表、边界条件、可见来源；线上内容可抓取 | FAQ/Schema 存在不等于排名或 AI 引用 |
| GEO 可验证性 | 固定问题集中的品牌提及、正确事实、可访问引用 URL、AI referral | 代理搜索/普通网页搜索不得冒充生成式引擎引用 |
| 执行健康 | dsh exit、有效当日报告、bus/scheduler/日志一致、线上 diff | mtime、AUTO-FILLED、wrapper=0 不得单独证明成功 |

## 2. 资源分配：三市场不走同一张内容清单

### 2.1 zh-hk：先兑现已有展示，优先级最高

**主攻：海报、食品包装、纸袋、急件；书刊作为第二梯队。**

- 海报：已有展示与接近首页查询，优先核对搜索意图、主承接 URL、真实价格/数量/纸质/交期、稿件确认与急件边界。
- 食品包装：先清除未经证实的食品接触/FDA/FSC 等声明，再补可证明的材质、用途、打样与报价输入。
- 纸袋：既有内链保留；补充袋型差异、数量、材质、手柄/承重仅在有真值时写。
- 急件：把“生产时间、稿件确认、数量/工艺限制、运输/取货”拆开，禁止无条件即日承诺。
- 竞品基准是 e-print/Bannershop 的采购信息清晰度，不是照抄价格或承诺。

### 2.2 en：小批试单与专业采购答案，拒绝廉价词堆叠

**主攻：small-batch stickers、doujin/saddle stitch、china/catalog printing；包装在真值拍板后跟进。**

- small-batch stickers：主词排名已接近首页且零点击，优先做页面级实验：首屏答案、真实 MOQ、数量/单位一致性、proof/sample 能力、交期边界、相关 guide 双向内链。
- doujin/saddle stitch：把页数、装订、表紙/内页对应英文规格、文件检查、活动倒排与生产/运输边界做成可比较资产。
- catalog：guide 负责选型与文件知识，PDP 负责采购规格与报价，不互相重复；MOQ/币种待真值。
- 包装：以 Packhelp 的低 MOQ/样品/3D 决策和 UPrinting 的 proof/生产时间边界为功能基准；没有本站能力证据就不写。
- eco-bag-gsm 当前只有诊断，先决定修复方向，不盲目扩写。

### 2.3 ja：C109 与冊子采购决策占据窗口期

**主攻：同人誌/C109、中綴じ/無線綴じ冊子；包装第二梯队。**

- 使用日本采购术语：部数、ページ、表紙、本文、オンデマンド、オフセット、入稿、データチェック、受付確定、出荷。
- C109 日期为 2026-12-29 至 12-31；页面应提供可执行的倒排清单和入稿检查，不虚构本站截稿、日本直送或活动价格。
- 对标 Raksul/Printpac 的结构化规格与纳期逻辑，不把日文页面写成英文内容直译。
- 日本 query-country 当前点击样本很小，7/14 天只做技术/方向判断，不能用短期 CTR 自夸成功。

## 3. 每个采购页的最小信息契约

每个任务只修改一个主 URL 及其必要内链，按适用性覆盖：

1. **一段直接答案**：产品适合谁、关键起订/规格/交期事实；不把宣传口号当答案。
2. **采购规格表**：尺寸、数量、材质、印刷/装订、加工、稿件、生产与运输边界。
3. **决策工具**：数量/盒型/装订选择、文件检查清单、活动倒排或打样流程；至少一个独特资产。
4. **条件与证据**：真值来源、适用范围、例外；无证据声明删除或条件化。
5. **主承接动作**：报价/WhatsApp/上传稿件，保留当前技术路径；不擅改组件或支付。
6. **hub–spoke 内链**：一个主 URL 承接主词，guide 与 PDP 分工，不建近重复页。
7. **机器可读取**：重要事实必须在 HTML 正文，不只藏图片；结构化数据与可见内容一致。
8. **复测登记**：上线日、冻结窗口、下一检查日、基线文件与成功/失败条件。

## 4. 任务评分与准入

任务队列：`.hermes/logs/strategy-task-queue.json`。GSC 车道负责提供证据与候选，daily 只消费 `READY` 且 `approval_gate` 已满足的任务；没有合格任务时允许 `NO_OP`。

分析师评分只用于排序，不冒充市场量：

```
score = 100 × (
  0.30 × 同口径需求证据 +
  0.25 × 排名/CTR 可修复空间 +
  0.20 × 采购意图与业务相关性 +
  0.15 × 真值/素材/执行包就绪度 +
  0.10 × 时间窗口
) - 风险罚分
```

- 需求证据以固定 28 天同窗口展示归一化；不得跨聚合范围比较。
- 缺真值、缺线上验收路径、写入范围过大或与其他车道冲突的任务不得进入 READY。
- 年賀状、贺卡资产、301 映射、冻结 title、未经拍板的业务数字继续受既有红线约束。

## 5. 7 / 14 / 28 天验证窗

### 第 7 天：只验技术与早期异常

- 线上 200、title/H1/canonical、正文真值、内链、结构化数据与抓取正常。
- 对比同词同页，不拿全站增长掩盖单页问题。
- 样本不足只写 `INSUFFICIENT_DATA`，不修改 title 追求短期波动。

### 第 14 天：方向性判断

- 非品牌展示、点击、位置与询盘事件是否同向；检查是否由其他改动、季节或索引变化造成。
- 高展示零点击且排名接近首页时，先审词页匹配与摘要，不立即重写正文。

### 第 28 天：SCALE / HOLD / FIX / STOP

- **SCALE**：技术与真值持续通过；同口径非品牌点击/有效询盘有可重复改善；把同一模式应用到下一小批。
- **HOLD**：数据不足、季节/外部因素无法排除或转化未接通；保留页面，延长观察，不宣称胜负。
- **FIX**：有足够展示但点击/询盘未改善，或有明确真值/意图/内链缺陷；生成一个具体修复任务。
- **STOP**：停止同类迭代，不等于自动删页/noindex。真值无法证明、连续两个同口径窗口恶化、或产生低质量询盘时停止扩张并交 K3 裁决。

## 6. 自动化学习与自进化边界

### 6.1 每日

- preflight 先验证 dsh、凭据、模型、锁、依赖；失败不调用 dsh、不提交生产文件。
- GSC 只更新证据和候选；daily 消费已批准队列；k3-review 汇总失败与待拍板，不伪造业务结果。

### 6.2 每周（weekly-meta 扩展为经营复盘）

- 汇总每条车道 OK/FAILED/BLOCKED/STALE、线上交付、词页变化和待拍板项。
- 对每个到期任务给 SCALE/HOLD/FIX/STOP；FIX 生成带 target/evidence/write_scope/next_check 的新任务。
- 复盘标题实验只处理已解冻且有证据的页面，禁止借复盘绕过冻结。

### 6.3 每月（monthly-matrix 扩展为资源重分配）

- 比较三市场与七簇的搜索、询盘、AI 面证据；决定下月加码/维持/修复/停止。
- 检查近重复、内耗、索引、AI 引用与转化覆盖率；没有转化覆盖率就先修测量，不假装 ROI。
- 生成下月队列，保留未通过任务的拒绝原因，避免隔天复活。

### 6.4 什么才叫“学习”

只有同时具备**改动前基线、具体改动、线上验收、到期复测、同口径结果**的记录才能进入 `learning-candidates.jsonl`。周/月任务可提议把规则提升为共享实践，但不得自动改写 prompt、自动扩大写权限或自动把单页偶然波动泛化为全站规则。
