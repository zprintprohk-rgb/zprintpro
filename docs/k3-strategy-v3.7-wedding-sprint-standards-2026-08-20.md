## 五、B / C / ToB 转化传导指标（全链路数学）

**三类客户的转化路径差异**：

| 客户 | 路径 | 询盘率基准 | 成交特征 |
|------|------|-----------|---------|
| B2C（婚礼/个人） | 博客/PDP → WhatsApp/quote | **3-5% 良性 / 8% 优秀** | 决策 1-3 天，客单 $150-400（整套） |
| 小 B（门店/活动） | 类目页 → 30 秒报价 | 2-4% | 决策 3-7 天，客单 $80-200，**复购率高** |
| ToB（企业采购） | about/trade-program → 尽调 → 询盘 | 1.5-3% | 决策 1-4 周，客单 $500+，年框 |

**北极星反推数学（M3 run-rate $1.5k/月）**：

```
L3 展示 15,000/7d × CTR 3% = 450 clicks/周
× 询盘率 3% = 13.5 询盘/周 ≈ 58/月
× 聊天成交率 25% = 14.5 单/月
× 混合客单 $150 = $2,175/月 ✅ 超 M3 目标 $1.5k
```

**敏感性**：询盘率每 +1pp = +$725/月；CTR 每 +1pp = +$725/月；成交率每 +5pp = +$435/月。**三个旋钮等效——但 CTR 和询盘率的数据都依赖今晚的 GSC OAuth + Supabase key，这就是为什么那 47 min 是全局咽喉。**

**度量落地**：008 quote_requests 表已备（source 字段区分 quote-form/whatsapp-cta/pdp-cta = B/C/ToB 分流基础），K3 跟单状态机（new→contacted→quoted→closed_won/lost）支撑成交率计算。
