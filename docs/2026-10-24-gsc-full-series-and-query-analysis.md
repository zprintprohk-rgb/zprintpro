## §0 三个先决事实（改变所有旧结论的口径）

1. **110 个 xlsx 全部是时间序列**（日期/小时 × 点击/展示/CTR/排名），**没有任何一个含查询词维度**。此前报告的全部词级数字（食品包裝印刷 9.81、食品包裝訂製 16.08、クラフト紙 108 展、零点击词表）来源是 GSC UI 截图或更早的 API 拉，**不可从现有导出复核**。
2. 本会话打通 API 后首次获得**可复核的词级数据**。以下全部词级结论以此为唯一依据。
3. 口径差异声明: query 维度 30 天合计 **8,070 展**，显著低于日期维度同窗合计（约 1.9 万）——GSC 对低频匿名查询不输出到 query 维度（Google 官方行为）。因此**词级结论只用相对指标**（单词 pos/CTR），绝对总量以日期维度为准。

## §4 结论与优先级重排（本轮核心产出）

1. **叙事纠偏**：全站处于历史高位增长曲线，「断崖恢复」框架退役；改为「**增长守住 + CTR 进攻 + US 修复**」三线。
2. **CTR 是第一杠杆**：30 天全站词级 CTR **0.83%**；仅速赢带 57 词就有 2,793 展在 pos 5-20——title 冻结纪律下，**meta description 与结构化富摘要是合规杠杆**。
3. **US 修复 = 第二杠杆**：-33% 的缓跌与 spam update 窗口吻合；B1c/图片/去指纹已做，恢复等重爬；需 query×country 拉取定位退场词（下批）。
4. **紙袋簇收口 = 第三杠杆**（新发现）：405 展的第二大簇，全部 striking distance，已有资产完备，只差 meta/FAQ 收口。
5. **数据纪律**：词级数据源已打通（API），后续每批动作前后都可拉数复核——「单方法结论」时代结束。
