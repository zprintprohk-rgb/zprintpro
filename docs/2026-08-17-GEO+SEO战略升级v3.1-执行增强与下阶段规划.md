## §4 战略方向 v3.1：对 v3.0 的四点增强（PM 判断，标注为判断）

### 4.1 增强一：设立"首页位保卫战"机制（新）

当前 12+ 个 top10 页面贡献了几乎全部 75 clicks。这些位置有两个属性：**是资产**（每个位置每周稳定产出 1-5 clicks），**也是靶子**（排名波动 ±3 位就会跌出首页）。建议：

- GSC_Data agent 每周三拉取后，自动生成"top15 词表 + 变化标红"：排名升 >5 位的页 → 加内链；跌出 20 的页 → 告警 + 48h 内人工审查。
- 对 rank 8-15 的"临界词"（大信封、月曆印刷、餐牌印刷、紙袋印刷、paper bag print file requirements）做**巩固优先**：meta 重写 + 内链指向 + FAQ Schema 三件套，同一周内完成。
- 验收指标：8/21 复测 top10 词数 ≥12（守住存量），90 天目标 50 个不变。

### 4.2 增强二：US 从"冷启动黑洞"切换为"摘果期"（提速）

v3.0 原定 US 走 W2-W4 节奏，但 8/17 数据（4 clicks + 657 imps + 2 个首页位）证明播种期比预期短。建议把 v3.0 §4.3 的三个动作全部提前到 8/18-8/22：

1. **small-batch-stickers（rank 5.5，0 click）**：FAQ 5 对（含 MOQ/价格/交期具体数字）+ 价格表 + 样品档（10 张起，对标 Sticker Mule）——这是全站 ROI 最高的单页动作。
2. **poster-printing-price-guide（rank 8.98，已有 click）**：内链加固 + 相关 SKU 交叉链接，做成 en 流量枢纽。
3. **catalog-printing 集群**：china catalog printing（rank 24）+ catalog printing（rank 38）有真实需求，en 支柱页候选。

### 4.3 增强三：GEO 执行强度上调，Batch B 列为"第 0 优先级"（不变但加权）

8/15 手测 0/4 + 零点击趋势数据共同指向：**GEO 基础设施（robots/llms.txt/schema）已就绪，卡点只剩两个**——Batch B 三输入（X URL / LinkedIn URL / IndexNow key，PENDING 7 天）与实体内容注入。执行建议：

- **40 字答案块标准化**：每篇 v8 博客、每个类目页顶部嵌入"直接答案块"（问题 + ≤40 字答案），同时喂 AEO 零点击位与 AI 引用。
- **每篇内容 3 个可引用数据点**（带来源日期）——Martinez 2026 实证：统计数据使 AI 引用率从 19.3% 升至 25.2%。
- **FAQ Schema 从 12 页扩到 14 类目页全覆盖**（Ransen 2026：+41% AI 引用几率）。
- ジープリント 品牌词：8/9 拍板后仍 0 收录，30 目录提交必须与 Batch B 同步启动（8/23 前完成，对应 8/23 复测 ≥1 imp 的目标）。

### 4.4 增强四：封面图/产品图路线固化（从实验到 SOP）

8/14 V17 事故（239 张图丢失）+ 8/16 65 篇 cover 全量 revert 两次实验共同证伪了"批量 AI 生图直接上线"路线。固化 SOP：

- **博客 cover**：单篇精选实拍/设计图（≤120KB webp），K3 拍板单篇推，脚本自动选图仅作**评分辅助**（建议权重调整：设计美感 35%→50%，与 K3 人工偏好对齐，用 5-10 张人工校准样本训练），终审权在 K3 眼睛。
- **PDP 产品图**：维持 K3 8/11 拍板——F1 设计师外包（印刷级 CMYK+出血+工艺层）+ F4 代码生成兜底；AI 出图仅作概念参考，不上 PDP。
- 87 SKU V20.9 重出：先测 3 张代表图（BC-001/ST-001/FL-001）验证 anti-draft 是否生效，再决定是否批量。
