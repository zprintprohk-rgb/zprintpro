## 一、核心战略洞察：可验证性 > 数字大小

B2B 信任研究（SaaSHero 2026-06 / CrazyEgg 2025-09 / WSI 2025-05 / WhatIfDesign 2026-02）交叉验证的 4 条硬事实：

1. **82% 的 B2B 买家重视供应商资质认证**；认证标识放在 CTA 旁，表单完成率 +32%（A/B 实测）
2. **信任信号 +20-40% 转化**，但**假信号一经发现，毁掉页面上所有真信号**——「企业采购尽调是标准动作，一个伪造信号就足以让你从中标名单除名，且无法恢复」
3. 带真人照片+全名+公司+量化结果的 testimonial，记忆度显著高于纯文字（p=0.0035）；「Great service! — Anonymous」式通用好评是负资产
4. 企业买家优先级排序：**合规认证 > 同行业案例（带数字）> 客户 logo 墙 > 团队真人 > 媒体报道**；SMB 买家才是「易用 testimonial + 快速上手」

**对 ZprintPro 的推论（这是本次审计最深的发现）：**

当前 about 页的 stats（1,000+ 客户 / 15+ 年 / 79 国 / 98% 好评）全是**不可验证的自证数字**。对 C 端这些数字无害；但对 about 页真正的目标读者——要做尽职调查的企业采购——不可验证的大数字 = 触发怀疑，而不是建立信任。

## 二、NAP 冲突裁决（P0，需 K3 一句话拍板）

**发现的内部矛盾**（代码实证，非转述）：
- `src/lib/seo.ts:1024` 注释（2026-06-28）：「NAP.address 保留 zh-hk 虚拟 HK 觀塘（灰色合规，GSC NAP 信号）」
- K3 8/7 拍板 + AGENTS §13.10（2026-07-05）：真实主体 = 深圳，「法律公示 + Footer + siteConfig.address + schema.org 都已改为深圳实体」

**6/28 的灰色合规决策已被 8/7 拍板覆盖，但代码没跟上** —— about 页 schema 写觀塘、legal 页写深圳，**站内自我矛盾是最差结局**（比写任一地址都糟：尽调客户 100% 会发现）。

**裁决建议：统一改深圳。** 理由：
1. about 页的目标读者是企业采购，不是「香港印刷」本地词搜索者——本地 pack 排名损失由 service-areas 页和「顺丰本地 24h / 港币结算」服务承诺层承接，不需要假地址
2. §13.10 NAP 脱钩原则：NAP 层 = 真实（深圳），内容层 = 本地化（香港场景词照用）——这个原则在 about 页同样成立
3. GEO 层：AI 引擎交叉验证实体时，schema/legal/footer 三处一致 = 实体置信度↑；矛盾 = 降权

**诚实声明代价**：zh-hk「香港印刷公司」类本地词排名可能短期承压。缓解：service-areas 页强化 HK 服务覆盖 + GSC 监控 2 周。
