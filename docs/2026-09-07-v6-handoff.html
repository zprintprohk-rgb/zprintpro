证据链:

  • 9000px 小窗实测:PLP 内容 8410 结束、PDP 8530 结束,footer 深蓝渐变渲染正常;
  • 识图裁决:空白带内零痕迹(无线/无字/无占位框),y≈16400 出现完整第二份页头(logo+导航+左栏+finder);

修复前 PLP 桌面 837KB 拉丝铺满 29600px 是真实渲染 bug,已由嵌套手术+flexfix 修复;修复后真实高度 8456px。

环境注意事项(后续接手必读)

  • Chromium headless 超高截图(>16384px)有图块伪影:0-16384 渲染第一份页面,16384 起重复渲染第二份;
  • Chrome headless 间歇 0 字节(16000 窗+375 宽高发);Edge(msedge.exe 同内核)实测更稳;
  • --user-data-dir 导致截图 0 字节,禁用;--dump-dom 本环境持续空输出;
  • GLM 识图通道(本地 WinError 10061 / 网关 403)不可用,像素法+轮廓染色法替代;
  • 移动端 PDP fixed 报价轨(mob-rail)污染内容末行测量,扫描需排除视口底部区域;
  • 截图必须断言:尺寸断言+内容体检(末行达标+无 >1000px 空洞+footer 深蓝校验),防「渲染一半就拍」。
