## 三、数据对账规则

1. 周报数字必须能对到落盘 JSON/导出文件，抽查差异=0 或书面说明；
2. GSC 导出窗口固定 7d（周一致周二更新口径统一），窗内批次改动日期单独标注；
3. 判定纪律：任何「达标」结论必须附原始数据路径；「不达标」触发登记册预案（见 risk-register.md）；
4. 每月 1 号月度复盘（v4.0 §7.4 六项口径）+ 半年路线图季度校准。
