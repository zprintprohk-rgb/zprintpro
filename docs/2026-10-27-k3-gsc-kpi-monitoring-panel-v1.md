## 三、口径纪律（禁止混算）

- §1 = date×page；§2 = 词级口径（zh=opportunities CSV query 口径 / en·ja=locale_opportunities 相关市场过滤）；§3 = query×page×country，locale 按落地页 URL 前缀归属，同一 query 落多 locale 分别计入。
- 三个口径的展示/点击总数**互不相等**（GSC 匿名化与聚合范围不同），只看方向与词级排名，不做跨口径相减（双引擎策略 §2.1）。
- GSC 展示 ≠ 市场搜索量。
