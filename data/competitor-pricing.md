## 八、EN/JA 市场价格策略建议

### 8.1 当前定价模型问题

```typescript
// 当前模型（固定3×）
'en': { rate: 0.384, symbol: 'US$' }  // 0.128 USD/HKD × 3
'ja': { rate: 58.5, symbol: '¥' }     // 19.5 JPY/HKD × 3
```

**问题：**
1. **未考虑品类差异**：贴纸（轻）和包装盒（重）使用相同倍数不合理。
2. **未考虑运费**：海外运费对低价值重货影响巨大。
3. **未考虑 PayPal 手续费**：3.5% 的手续费直接侵蚀利润。
4. **与 Vistaprint 竞争**：名片 3× 后价格过高，完全无竞争力。

### 8.2 建议分级定价模型

| 品类分级 | 定义 | 建议 EN 倍数 | 建议 JA 倍数 | 理由 |
|----------|------|-------------|-------------|------|
| **A级：轻量高值** | 贴纸、单张 | 1.8-2.2× | 1.8-2.2× | 运费占比低，价格可接近本地 |
| **B级：中量中值** | 名片、海报、信封 | 2.5-3.0× | 2.5-3.0× | 运费适中，保持竞争力 |
| **C级：重量低值** | 包装盒、纸袋、书籍 | 3.0-3.5× | 3.0-3.5× | 运费占比高，需覆盖成本 |
| **D级：特急服务** | 即日/次日印刷 | +20-50% | +20-50% | 速度溢价 |

### 8.3 具体调整建议

#### 名片类（B级 → 需降至 2.0-2.5×）
- 当前：啞膠咭片 100张 HK$110-190 → EN 3× = US$42-73
- Vistaprint 对标：约 US$15-25/100张
- **建议倍数：2.0×** → US$28-38/100张，仍高于 Vistaprint 但可强调"香港品质+WhatsApp客服"
- 或定位高端，保持 2.5× = US$35-48，强调"Premium Quality + Same Day"

#### 贴纸类（A级：1.8-2.0×）
- 当前：防水貼紙 HK$0.22-1.0/张 → EN 3× = US$0.25-1.15
- Vistaprint 对标：约 US$0.20-0.60/张
- **建议倍数：1.8×** → US$0.15-0.69/张，**有竞争力**

#### 宣传单张（A级：1.8-2.0×）
- 当前：A4 flyer HK$0.18-0.65/张 → EN 3× = US$0.07-0.25
- Vistaprint 对标：约 US$0.10-0.30/张
- **建议倍数：2.0×** → US$0.08-0.27/张，**有竞争力**

#### 海报类（B级：2.5-3.0×）
- 当前：A2 poster HK$10-35/张 → EN 3× = US$3.8-13.4
- 美国本地 poster 打印：约 US$5-15/张
- **建议倍数：2.5×** → US$3.2-11.2，**合理**

#### 包装盒/纸袋/书籍（C级：3.0-3.5×）
- 当前 3× 可能仍不够覆盖运费
- **建议倍数：3.2×** 起，或单独标注"Shipping not included"
- 考虑设置最低订单金额（如 US$100）以覆盖运费

### 8.4 PayPal 手续费模型

| 订单金额 | PayPal 费率 | 实际到账 | 建议加价 |
|----------|------------|----------|---------|
| US$0-50 | 3.5% + $0.30 | 96.2% | +4% |
| US$50-200 | 3.5% + $0.30 | 98.1% | +2% |
| US$200+ | 2.9% + $0.30 | 98.8% | +1.5% |

**建议**：在分级定价基础上，所有 EN 价格额外 +3% 以覆盖 PayPal 手续费。
