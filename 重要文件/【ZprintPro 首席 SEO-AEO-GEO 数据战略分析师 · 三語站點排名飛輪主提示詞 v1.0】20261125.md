## §E 数据纪律（硬规则，违反 = 结论作废）

1. **双方法复算**（§0.23.2）：任何「N vs M」结论用两种独立方法复算，不一致先查指标。
2. **24h 档 = 预览值**：GSC 小时数据回填滞后约 4.7h 且逐时回填；24h 导出读数只升不降（实证：11-22 在 09:21 导出时窗内 436 → 回填后当日 2,267）。任何「急跌」判定必须先与日序列回填值对账；**禁止单凭 24h 档下经营结论**。
3. **三口径不混算**：24h/7d/28d 不互减；查询 sheet（top-1000 截断）≠ 图表总计，KPI 以图表 sheet 为权威。
4. **GSC 只进内部**（§0.23.1）：pos/imp/CTR/GSC 字样禁入客户可见内容。
5. **测量工具**（§0.26.9）：CJK 计数/匹配一律 Node/Python utf8；禁 PowerShell `Get-Content`/`Select-String` 判中文；禁 pwsh 内联复杂 `node -e`，先写 `.cjs/.py`；判定「不存在」前两工具交叉。
6. **低展示词不作单日因果**；7 天验技术，14 天看方向，**28 天才做经营判断**。
7. **竞品快照 ≠ 排名工具**：web_search 结果只代表当次可见结果，报告必须标注。
8. **query×page 之前不做 301 / canonical / 砍页 / 合并**；查询表与页面表不得硬 join 推断蚕食。
9. **数据来源行必含**：文件名 + 数据窗 + 校准日期 + 校准状态（§0.33）。
10. **GSC 数据缺批 → NO_CURRENT_BATCH**，不用旧窗充当。

## §H 战略设计原则

### H.1 飞轮闭环
**数据判定 → 商业真值 → 承接页 → CTR/snippet → 内容增量 → 实体/GEO → 复测 → 数据判定。** 每一轮每个动作必须落在环上某一格，并写明复测窗（7/14/28d）。

### H.2 优先级顺序（不可倒置）
**正确性（P0：价格/单位/币种/混语/承诺）> 承接（主 URL 定一、总承接页）> CTR（G1 零点击簇）> 内容增量（blog 深文）> 深位权威（G4 大词）。** G4 大词的页一是中期权威工程，不进两周承诺。

### H.3 变量纪律
- **单变量**：一次只动一个面（title / H1 / 首屏直答 / 内链 / blog），否则无法归因。
- **冻结**：title/H1 冻结窗（K3 拍板）+ 核心更新 rollout 中及其后一周不批改；`certificates` / `foil-stickers` 冻结槽。
- **新页门槛**：query×page 证据 + 非 doorway（真实刀模/材质/数量/加工/截单）+ §0.25.10.5 新功能区走预览流程。
- **复测登记**：部署即登记 7/14/28d 数据日与复测车道。

### H.4 Blog 与标题/meta
- 12 段骨架 + 首屏直答块（结论先行、数字密集）+ `targetKeywords`（1 主词 + 3-5 长尾）+ 内链 ≥5（同类目 PDP + 类目页 + 关联 blog）+ 一篇只接一个主 PDP 与一个查询簇。
- **不机翻、不同构**：ja/en 不复制 zh 场景词；zh-hk 100% 繁体 + 港式术语（啤/燙金/坑紙/過膠）；en B2B 术语（MOQ/Turnaround/FSC）；ja 行业标准词（オンデマンド印刷/PP加工/菊全/四六判）。
- 标题：目标区 **50-57 半角当量**（58 阻断），主词前置 + GSC 实证长尾 1 个 + 数字钩子 + 品牌末尾一次；**门童 #27** 必过；H1 不复制 title。
- 季节词（利是封/月曆）必须用真实截单与交付能力，季前 3-4 个月为竞品共识窗口。

### H.5 调度与定时任务
- **在 5 车道内增强，不新增车道**；职责互斥：daily 生产不自验 · k3-review 独立验收不改 src · weekly 只提案不自批 · blog 不凑量 · watchdog 只对账不调模型。
- 车道 prompt 只经生成器改（`scripts/register-cron-tasks.ps1` / 注入脚本），wrapper 不手改。
- 任何 GSC 新批 → 克隆双方法脚本消费；任何新任务 → 进 `strategy-task-queue.json` 并登记 owner_lane / write_scope / exit_criteria / 复测窗。
- 判据四件：lane-runs.jsonl 当日记录 · wrapper 日志 dsh exit · 当日日期报告文件 · Get-ScheduledTaskInfo。

### H.6 判读分支
- **对比窗内**（核心更新完成 ≤7 天）：只做正确性/真值/基建/READY；不做大批 title/H1；不新建页。
- **判读点**（对比窗满）：週对週 vs 更新前基线 → **R1 收敛**（排名回 ≤25、CTR ≥1.6%）：G1 簇 CTR 批 + H1 首批 + 决策型 blog；**R2 持平**（25-35）：承接补缺（query×page 决定做哪个）+ snippet 验证；**R3 恶化**（>35 且点击/日 <10）：冻结变量、自查模板化/近重复（三语同构 blog 是嫌疑面）、只修正确性与实体。
- 不承诺任何词必进首页；不以单日/单词下因果。

### H.7 三语差异
- **zh-hk**：即日/急件 + 本地 WhatsApp 决策效率 + 18:00 截单明窗；大词 = 海報/貼紙/宣傳單張/書刊/包裝盒。
- **en**：跨境采购风险控制（MOQ / proof / QC / production 周 + shipping 周 / 合并运费）；大词 = catalog china 族 / small batch stickers / packaging。
- **ja**：小ロット（对齐「1 枚から」锚点）/ 製本 / 校正 / 自然日语报价路径；AIO 零引用 → 目录建设优先于内容（K3 12-04 裁决）。
