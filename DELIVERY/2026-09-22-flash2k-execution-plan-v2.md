# V27.5 生图执行方案 v2.0 · Flash 2K + 90 分质量门（唐总 2026-09-22 20:51 指令）

## 一、指令拆解与规格
| 项 | 规格 |
|---|---|
| 引擎 | Seedream 5.0 Flash（doubao-seedream-5-0-flash-260915，已验证可用） |
| 尺寸/比例 | 2K（2048×2048）1:1 |

| 旧图 | 以前生成的图不作为成品；不合格的归档另存 |
| 批次制 | 每批 5 SKU（60 张）确认后再下一批 |

## 二、90 分评分体系（六维 100 分）
| 维度 | 满分 | 扣分规则（红线项直接归零该项） |
|---|---|---|
| 产品逻辑与结构 | 25 | 金属鸡眼扣/气眼混入纸绳袋 −15；车线缝线痕迹 −10 |
| 文字准确 | 20 | 乱码/错拼/无意义字符 −15 |
| 布光红线 | 20 | 投影落在产品上 −10；逆光/暗调侧逆光 −8；焦点模糊 −5 |
| 构图占比 | 15 | 产品占比 <60% −8；>97% −5；视角错误 −5 |
| 水印与证书标 | 10 | 任何水印 −10；任何 FSC/ISO/认证标 −5 |
| 色彩与花卉 | 10 | 花卉占比 >30% −8；主色调偏离该 SKU 指定方案 −5 |
| **合格线** | **≥90** | 85-89 分进人工复核队列（唐总终审）；<85 直接淘汰重试 |

**评分实现 v2（关键改进）**：识图 API 强制返回 JSON 结构化判定（`{"metal_grommet": true/false, "stitching": true/false, "shadow_on_product": true/false, "backlight": true/false, "text_garbled": true/false, "watermark": true/false, "cert_mark": true/false, "floral_pct": 数字, "occupancy_pct": 数字, "text_transcript": "..."}`）——自由文本解析的误报问题（试点实测：转写区提到 FSC 被误判为证书标、否定句漏判）从根上消除，计分完全确定可复现。

## 三、生成-审查-重试-归档流水线（每张）
```
生成（Flash 2K，一次一张）
  → PNG 原图落盘 PNG原图/{档案名}.png
  → webp 另存（1200²、<120KB、alt 內嵌）
  → 识图评分（JSON 结构化）
  → ≥90：进入交付位（OUT_ROOT 根，档案命名）
  → 85-89：人工复核队列（唐总终审，不自动淘汰）
  → <90：带缺陷标签重试（提示词针对性强化，最多 3 次）
  → 3 次仍 <90：移入 _rejected/ 文件夹 + 记入淘汰台账（唐总终审定夺）
```

## 四、目录结构
```
v27_5_raw/
├─ *.webp              ← 交付位：仅 ≥90 分成品（1200²、<120KB、SEO 命名、alt 內嵌）
├─ PNG原图/            ← 对应 2K 原始 PNG（先存 PNG 再另存 webp，唐总 15:20 规格）
├─ _rejected/          ← 不选用/淘汰图（另存文件夹，含 score_report.json 逐张失败原因）
├─ _qa_reports/        ← 每张评分明细（六维分数 + 识图转写全文）
├─ _retry_log/         ← 重试记录（缺陷标签 + 强化提示词 diff）
└─ _ledger/            ← tasks.json SSoT / 断点 / 补丁记录 / 工具
```
